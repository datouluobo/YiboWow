# YiboReputation

依赖 YiboCore 的多角色声望浏览与比较插件。

新版界面采用明确分工：

- 主窗口提供“声望为行、角色为列”的完整账号矩阵，用于浏览、搜索和角色间比较。
- 悬停默认显示当前角色按资料片折叠的声望树。
- 悬停也可切换为最多 10 项重点声望的账号监控矩阵。

三个表面共享 Core 的稳定 faction ID 快照、角色范围、数据状态和数值格式，但根据任务使用不同布局。入口、窗口壳、角色排序和设置工作台仍由 YiboCore 统一承载。

实现以 `实施计划.md` 的新版方案为准：主窗口为唯一账号矩阵；悬停在当前角色树与监控声望矩阵之间按设置切换。
