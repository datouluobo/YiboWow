# YiboReputation 双端共享矩阵实施与验收

2026-11-27。Mists 1.8.0 和 Forever 0.2.0 工作树完成分层。两端沿用现有版本号，构建仅使用临时目录。

## 界面与数据边界

- 两端加载同一个 `Common/AccountMatrixView.lua`，由 `Common/Page.lua` 注册 Core 页面和业务入口。阵营为行、角色为列。主页面的搜索、关注操作、筛选、排序、进度条、分页和详情使用共同实现。悬停用相同渲染器，只取有数据的关注阵营，按关注顺序显示。长列表使用 Core 滚动视口，行控件按可见范围复用。
- `Common/Display.lua` 统一等级名称、颜色、进度文案和状态。目标适配层判定原生数据的含义并提供本级进度、满级标记、快照时效和附加字段。两端共用 `Locales/Interface.lua` 的中英文资源。
- `Mists/` 保有资料片目录、公会分组、好友度和累计进度选项、Nomi、旧 Core 快照导入，以及 `action.targets`。10 项关注上限继续由 Mists 规则执行。
- `Forever/` 保有受限值检查、原生事件与动态发现、普通声望区间验证、当前角色采集和会话净变化。账号矩阵可对照已经保存的角色快照，旧观察标记为过期，会话变化只对当前有效观察可用。关注数量无上限。无限服尚未发现好友度型声望。
