# 宝石候选筛选修复

日期：2026-10-24。源码版本：Mists 1.5.1 工作树；状态：代码完成，离线通过，客户端待复测。

## 范围与规则

背包宝石候选先通过目标客户端 `ItemSparse.Gem_properties > 0` 确认可镶嵌性，排除碧玉（52182）等未切割材料。红、黄、蓝、棱彩普通孔均接受普通单色、混色与棱彩成品宝石；孔色是否匹配属于插槽奖励条件，不作为普通孔允许镶嵌的限制。多彩与染煞孔分别只接受对应专用宝石。背包、可制作候选和目标适用性共用同一判断，炼金转化得到的原石也不能成为候选。非制作来源的可镶嵌宝石继续保留。未收录物品或客户端物品信息未就绪时不猜测可用性。

静态集合来自 Mists 客户端 5.5.4.69934，共 1234 项，由 `_NonRelease/Tools/GenerateGemCatalog.py` 生成；生成工具支持输入本地 CSV 或从固定构建下载。更新客户端目录时须重新生成并验证。来源：<https://wago.tools/db2/ItemSparse/csv?build=5.5.4.69934>。

- 迁移单元：颜色匹配规则、背包候选容器 API 读取及可镶嵌物品目录，位于 `Mists/Gems.lua` 和 `Mists/Data/GemCatalog.lua`；共享页面消费 `Addon.Gems`。页面的其它职责未扩大迁移。
- 影响目标：Mists。Forever 仍使用独立只读加载链，本次未接入候选能力或修改其文件。
- Mists TOC 在页面前加载新模块且各加载一次；旧 `AccountPage.lua` 保留为当前页面入口，已移除其原候选实现，覆盖安装保留旧文件也不会加载第二份候选实现。未改变插件技术名、安装目录或 SavedVariables。
- Core 公共能力：候选扫描和物品可镶嵌性属于业务与客户端适配，现有 Core 无对应可替代公共契约。页面现有 Core 托管物品操作及 API13 语言能力调用保持不变；本次无新增玩家文本、版本要求或接入状态变化，因此无需变更公共能力台账。
