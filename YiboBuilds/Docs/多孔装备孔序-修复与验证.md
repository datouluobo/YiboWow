# 多孔装备固定孔序

日期：2026-10-24。Mists 1.5.1 工作树；代码完成、离线验证通过、实机待验。

## 问题与行为

旧采集从装备提示中读取孔序，再按 `GetItemStats` 的颜色计数补齐漏读孔。镶嵌后的提示可能省略部分孔，导致剩余孔先被读取，漏读孔随后补到末尾；宝石仍按原生索引读取，从而产生孔位或孔色变化。

本次以客户端 `ItemSparse.SocketType_0..2` 的原生顺序作为已收录装备的固定孔序，空孔与已镶嵌孔使用同一个索引。腰带扣、锻造和武器额外棱彩孔排在原生孔之后。即使提示只剩额外孔，也保留全部原生孔的位置。原生孔数同样来自固定目录，避免受提示与空孔数量影响。未知装备继续使用原有提示／计数采集，不根据宝石颜色猜测原生孔色。

显示方向：待应用宝石面板按装备提示从上到下的原生孔序列出，并按同一孔索引执行选择和镶嵌。人偶左侧装备从左到右排列，右侧装备从右到左排列，均从装备图标向中间人偶展开；武器栏沿用现有图标旁的展开方向。此处为共享页面布局规则，无新增客户端差异或 Core 能力调用。

新增目录收录 15284 件带原生孔装备，按 56 种序列分组，约 113 KiB。来源为固定 Mists 客户端 5.5.4.69934 的 [ItemSparse](https://wago.tools/db2/ItemSparse/csv?build=5.5.4.69934)；通过 `_NonRelease/Tools/GenerateSocketCatalog.py` 生成，支持本地 CSV 或固定构建下载。SocketType 使用类型索引，染煞为 5、棱彩为 7；未接入的特殊类型保留 unknown 占位。

## 迁移与加载

- 完整职责单元：原生孔序目录、提示解析、孔类型补全及原生孔数读取，归入 `Mists/Data/SocketCatalog.lua` 和 `Mists/SocketReader.lua`。
- `Snapshot.lua` 通过 `Addon.SocketReader:Read`／`NativeCount` 消费有序结果。其它装备、附魔、工程采集职责保持原位；宝石已安装状态与图标仍由同一个装备快照生成。
- 新扫描器使用独立隐藏提示框名 `YiboBuildsSocketScanTooltip`，不与仍保留的附魔扫描器复用同名全局框。
- Mists TOC 在 Snapshot 前各加载一次目录和扫描器；旧 Snapshot 保留为快照入口，旧孔序实现已从该文件移除。覆盖旧文件不会引入第二份孔序实现。安装目录、插件技术名与 SavedVariables 不变。
- 影响目标为 Mists；Forever 的独立只读采集链不加载本次文件。未将本次结果外推到 Forever 验收或发布状态。
- Core 审查：本次涉及客户端装备孔序与业务快照，无可替代的 Core 公共孔序能力。现有 API13 版本检查、账号快照、角色身份、语言与操作调用边界不变；无能力接入状态变化，无需修改迁移台账。未新增玩家文案，提示中的客户端名称按 API 原文解析。

## 实机待验
