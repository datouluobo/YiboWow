# 统一账号主窗口实施与验证

2026-11-24，基于已确认的 MoP 紧凑布局试点 `1e5c4b9`，在 `codex/unified-account-windows` 独立工作树实施。Core 托管的账号主页面、设置工作台及注册到其中的独立插件设置页共用 `736 × 544` UI 单位外框。屏幕安全区域更小时取其宽高上限。Core 保留窗口锚点和旧按页尺寸数据，主窗口本轮仅使用统一尺寸。

## 页面适配

| 范围 | 调整 |
|---|---|
| Core 三目标 | 主导航和设置导航共用固定宽度。角色档案度量当前字段，固定角色身份列，按内容宽度分页。统一设置右栏按可用宽度排版并纵向滚动。 |
| 副本进度、专业配方（Mists） | 延续已确认试点。副本按版本和类型筛选，配方按专业、类别和搜索组织成虚拟滚动列表。 |
| 装备对比（Mists） | 保留角色栏，在同一内容区切换装备与天赋／雕文。装备详情使用同一位置。 |
| 待办与行动中心（Mists） | 待办固定左侧角色身份，项目组按真实宽度分页。行动中心压缩总览、目标表单与副本目标控件。 |
| 邮件、库存 | Mists 邮件角色栏和标签适配窄页。Forever 邮件降低内容区最小宽度，库存来源筛选按宽度换行并调整物品网格。Mists 库存沿用页面现有紧凑布局。 |
| 其它托管页 | 调整 BeastPaths 离线宠物页、Legendary、Mists 货币、Forever 专业配方和声望，以及 AutoOpen 和 QuestBlocker 设置。其它注册页面自动使用统一外框，保留其业务视图方向。 |

普通主页面在固定外框内依据字段宽度、实际纵向沟槽和筛选控件重新排版。只有屏幕小于关键业务控件的最低可用尺寸时，Core 才为业务内容视口提供必要的滚动。Broker、小地图、信息条悬停保留自然尺寸。独立的 HUD、游戏原生界面、业务弹窗继续使用各自的尺寸规则。通用契约见 [Core 窗口尺寸与溢出契约](../YiboCore/Docs/Core-0.3-窗口尺寸与溢出契约.md#66-固定账号主窗口和紧凑布局)。

## 目标与兼容性

- Mists、Forever 和 Retail 共用 Core 窗口布局。业务变更分别在现有共享 UI 或目标 UI 内完成，无新增客户端专用 API。业务数据来源、角色准入和已有模式保持原有契约。
- Core 原有 API14 保留，新增 `account-compact-layout:2`，继续兼容试点 v1 测宽接口。Todo 检查既有 `account-surface-budget:2` 和预算／分页方法，版本不足时沿用其升级提示及初始化停止逻辑。其余消费端沿用现有能力门槛。
- 本轮没有修改 TOC、XML、初始化注册链、版本号或 SavedVariables 名称和 schema。统一构建验证使用现有源清单与安装包映射。Mists、Forever 使用对应目标清单，Retail 源码使用 `_Mainline.toc`，BeastPaths 沿用已登记的 Universal 例外。误目标写库、Core 就绪、单次初始化及覆盖更新加载链不涉及本轮变更，相关实机证据继续按已有版本登记。

## MoP 集中实机

2026-11-24 将 MoP 的 15 个正式 Yibo 插件目录联接切到 `D:\Development\YiboWow-unified-account-windows`。已逐项核对新联接与原联接，原联接存放在 MoP 客户端 `Interface\YiboUnifiedWindowBackup-20261124`，其中 `Junctions.json` 记录原目标与测试目标。发布外探针沿用已有联接。需要回滚时退出 MoP，将测试联接移出 `AddOns`，再把备份中的原联接移回。此次切换未直接操作 `WTF`。

本次客户端为 Mists `5.5.4/71089`、`zhCN`，实测 Core 能力 `account-compact-layout:2`，`UIParent` 有效缩放 `0.75`。中文行动中心主窗口初测 `736 × 543.99994` UI 单位，高度按渲染浮点精度记为 544。

用户截图指出构筑角色名被截断、首领／货币／任务屏蔽分页覆盖表头、任务屏蔽处理模式移出窗口。修订后主窗口和设置共用 `800 × 544` UI 单位。构筑按实际名字、等级与滚动沟槽测宽，所有服务器时另起一行显示服务器；待办同 Core 测宽使用已配置的短名。邮件历史优先保留角色文字宽度。主窗口列分页区域由 Core 提供。任务屏蔽和声望工具栏按实际文本宽度摆放，必要时换行。行动中心底部翻页按钮按文本设宽，概览行动标题移到汇总内容下方。
