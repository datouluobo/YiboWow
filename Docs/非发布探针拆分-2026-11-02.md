# 非发布探针拆分记录（2026-11-02）

## 范围

本次把 YiboCurrency、YiboLegendary、YiboMounts、YiboTodo 的原生客户端观察从正式插件加载链拆为根 `_NonRelease/` 中的 Mists Classic 独立探针。四个新探针 Interface 为 `50504`，运行前检查 `WOW_PROJECT_ID == WOW_PROJECT_MISTS_CLASSIC`；错误目标不注册采样命令、不写入任何 SavedVariables。探针不依赖 Core，不读取业务插件私有对象，不改动 YiboCore 公共能力或迁移台账。

| 探针 | 独立目录/默认 TOC/游戏加载名 | Slash | 采样范围及所有权 |
|---|---|---|---|
| Currency | `YiboCurrencyProbe/YiboCurrencyProbe.toc` | `/ycp` | GetMoney、客户端货币列表和 API 能力；`YiboCurrencyProbeDB` |
| Legendary | `YiboLegendaryProbe/YiboLegendaryProbe.toc` | `/yep` | 任务、阵营、物品数量、装备 API；`YiboLegendaryProbeDB` |
| Mounts | `YiboMountsProbe/YiboMountsProbe.toc` | `/ymp` | 坐骑日志、Tooltip 单位/光环及冻结 source ID 的客户端名称解析；`YiboMountsProbeDB` |
| Todo | `YiboTodoProbe/YiboTodoProbe.toc` | `/ytp` | 原生任务日志、地图、能力和事件名；`YiboTodoProbeDB`，不存事件参数或角色身份 |

目录名与默认 TOC、玩家加载名一致。四项命令已登记在 `Docs/Yibo系列插件命令清单.md`；命令唯一性已对全工作区精确搜索确认。业务 `/ymt` 只提示坐骑原生采样已迁至 `/ymp`；`/ycu`、`/yle`、`/ytd` 的业务命令继续保留，其 probe/debug 子命令已移除。

## 迁移和存档

- 业务 `.toc` 已删除对旧探针文件的加载引用；YiboMounts 的 Tooltip 与 Bootstrap 不再调用探针模块，YiboTodo Bootstrap 不再转发事件给探针，Legendary 初始化不再自动采样。
- 旧探针读取业务状态、业务目录或把采样写入业务 SavedVariables 的实现已退役。原有业务 SavedVariables 身份不变；旧采样字段不主动清理或重置。新数据仅写各自独立 `*ProbeDB`。
- YiboMounts 的 `SourceFacts.generated.lua`、坐骑日志基线、纯数字事实输入、生成器、导入器和导入烟测已迁到 `_NonRelease/YiboMountsProbe/`。目录维护工具及业务目录仍保留于 `YiboMounts/_NonRelease/`。
- 旧 TOC/XML 或客户端留下的旧 Lua 文件因新业务清单不再引用而不会执行；未使用运行时代码删除磁盘文件。
