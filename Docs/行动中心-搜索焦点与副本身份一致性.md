## 当前行为

搜索框在目录筛选刷新期间保持显示，连续英文输入和中文输入法组合态均保留焦点。真正离开目录进入编辑或复制页时，继续由 Core 输入控件的 OnHide 清理焦点和未提交组合态。

AltoBoss 的 Mists 适配层统一旧目录与客户端难度身份。此次只对已核实的八个 TBC 团本应用 3→175、4→176；其它团本的普通/英雄和不同人数仍保持精确区分。SW 的维护目录、地下城手册、旧目标和当前锁定共用客户端身份176及对应显示资源。新增目标仍使用稳定副本/首领ID，不能按显示文字归并。

Hub 经原有 Core.Contracts 查询同一个 AltoBoss 来源；旧目标读取、编辑、添加与复制共用来源的标准化结果。来源 Normalize 可返回同一 provider 下的 identityAliases，Hub 验证其为字符串数组后，在 Lookup/Add/Update/PreviewCopy 判断历史身份。别名包含原来的角色、范围、首领集合和重复策略，不把不同角色、不同 Boss 或不同周期策略视为同一目标。

旧目标 ID、暂停/完成状态及历史保留。已有两份不同目标不做磁盘删除或批量清库；AltoBoss 按地图ID与规范难度只展示一列，同角色多个目标按首领集合并集展示，有整本目标时保持整本范围。进度与悬停继续调用同一来源判断，其他角色显示同难度的正常锁定。
