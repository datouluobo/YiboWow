2. **Mail 快照。** 输入 `/yma`。用已有邮件搜索发件人、主题或附件，再叠加一个有样本的分类，确认交集、计数、无匹配提示及清除后恢复列表。没有缓存时挪到本次打开邮箱后。其它分类按已有样本选测。
3. **Crafting 快照。** 输入 `/ycr`，用已有配方测名称或 ID、专业与学习状态的组合，核对条数和清除恢复。缓存里的未学记录只用来验筛选。原生未学对照与学习后变化继续等自然样本。
4. **Builds 人偶。** 输入 `/ybb`，看中央是否显示当前角色、装备位是否围绕模型排布。选一个有装备的槽和一个已有空槽，核对图标、名称及物品悬停。把窗口缩窄，确认切换为可读列表，再拉宽看人偶恢复。用已有快照即可，无需换装。
5. **Currency 金银铜。** 输入 `/ycu`，对照当时原生背包余额的金、银、铜位数和图标。若已开启入口悬停，确认文字余额与主窗口相同。无需制造金币变化。
6. **Reputation 声望筛选。** 输入 `/yrp`，用已观察阵营试名称或 ID，再叠加一个已有声望等级。核对匹配条数、清除后恢复、命中行仍显示原进度条。无需制造声望变化。
7. **银行。** 清除 Vault 搜索，切银行页后打开原生角色银行。空库先观察能否自动显示「已完整采集：无物品」，若停在待确认，等原生加载后点一次刷新，分别记自动或手动结果。有自然取出最后一件的条件时，核对不刷新也能变空。关闭原生银行，核对结果保留为历史。
8. **邮箱。** 将 Mail 切回全部邮件，并切到 Vault 邮件附件页。同一件附件对照原生、Mail 和 Vault。若有金币或 COD，查看原生详情并核对 Mail 金额，COD 可只看金额。正常取一个本来就要取的附件，确认无手动刷新时 Mail 和 Vault 都按实际取出数量更新。关闭邮箱，确认取件后的结果保留为历史。
9. **完整退出重登。** 登录同一角色后，先不打开原生银行和邮箱，也不刷新。核对 Vault 银行结果、Mail 收件快照和 Vault 附件数量与退出前一致。Builds、Currency、Crafting 和 Reputation 的既有恢复证据沿用。

可用任一有样本的新界面输入中文，确认输入法提交后才筛选，并核对悬停不沿用主窗口临时筛选。英文及手动语言模式留集中回归。既有背包／装备、银行非空存入、空邮箱、已对照的非空收件内容和 Crafting 已验采集沿用原证据。无条件项记待条件；一次汇总界面、银行、邮件及重登结果。
