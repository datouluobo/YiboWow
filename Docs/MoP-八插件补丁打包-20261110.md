# MoP 八插件补丁打包记录（2026-11-10）

本次按用户要求提升并打包 Mists 版本：YiboAltoBoss 2.8.6、YiboCore 1.12.14/API13、YiboCurrency 1.1.2、YiboLegendary 2.2.5、YiboMail 1.3.4-api1、YiboQuestBlocker 3.1.3、YiboTaskHub 0.6.4、YiboTodo 1.2.6。版本号与打包不代表实机验收、可发布或渠道发布。

Currency 目标源码清单为 YiboCurrency_Mists.toc，玩家包加载 YiboCurrency.toc；默认源码清单仅提示缺目标。入口检查实际客户端，Core API13 与能力检查通过后才初始化存储；登录与业务初始化有幂等保护。技术名、目录及 YiboCurrencyDB 存档身份保持；旧根目录 Lua 不再被新清单引用。统一构建器核对目标、Interface、加载引用与包内容。具体模拟证据和旧 TOC、覆盖检查见 Currency 双目标入口修复记录；本次版本的干净安装、保留旧文件覆盖、首次启动、重载及退出恢复仍待客户端验证。Forever 目标版本未提升，其已发包证据不外推至本次源码。

Mail 继续采用既有 MoP 源码和玩家加载清单 YiboMail.toc；本次版本变更没有更改目标入口、Core 依赖及检查、初始化幂等、存档身份或覆盖加载链，沿用既有职责和证据。批量清理代码及相关中文／英文资源随包纳入；离线退信及 UI 回归通过，客户端系统邮件识别、删除与保护验证待完成，详见 Mists 收件队列优化与验收。

其余插件本次仅修改目标版本信息；没有变更其入口或加载链、Core 契约、存档身份和文件迁移职责。各插件及目标的既有实机验证范围不因版本号变化而扩大。八项均经统一构建器 Mists 目标／Interface／引用／Lua 语法预检；Currency 的目标清单和迁移离线测试、Currency 和 Mail Forever 模拟回归、Mail 退信及 UI 回归通过。此前尚未完成的实机、语言与发行检查仍待完成。

Core 公共能力核对：本次新增差异为版本与既有 Currency／Mail 工作区改动；Currency 继续使用既有 API13、语言及角色能力，Mail 继续使用既有角色身份和确认组件，未新增 Core 公共能力接入。其它业务插件本轮仅提版本，不构成新的公共能力迁移；迁移台账无需因本次提版变更。
