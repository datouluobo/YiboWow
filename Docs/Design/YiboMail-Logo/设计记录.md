# YiboMail Logo 设计记录

## 阶段 1：功能语义拆解

状态：已确认。

用户于 2026-10-03 回复“继续”，确认本阶段语义与限制。

依据：仓库根目录 `WoW小图标制作工作流.md`、`Logo设计约定.md` 及 `Docs/YiboMail-产品边界与开发路线图.md`。

- 一句话功能：集中查看多角色邮件与附件，辅助收取和寄送。
- 推荐主意象：一封略微斜放、带封蜡的信封。
- 必要形状：信封主体、清晰的 V 形封口、中央封蜡；统一六边形外框作为系列结构。
- 系列归属：深青黑外框与一条连续青绿色识别线，继承 YiboCore 品牌结构，中心信封优先可读。
- 业务强调色：暖象牙色信封与琥珀金封蜡，突出纸质邮件的识别，同时与青绿系列色形成明度及冷暖对比。
- 干扰限制：不加入文字、金币雨、包裹堆、角色头像、时钟、双向箭头或场景背景；外围透明至画布边缘。
- 尺寸约束：先验证 24×24 与 32×32；整体徽章主体占画布至少 85%，最多 3–4 个主要视觉块，以粗轮廓和大块明暗保障识别。
- 现有资源：YiboMail 当前使用游戏自带 `INV_Letter_15` 作为插件列表与入口图标；Media 内为收发件 UI 概念图，未发现专属 Logo。
