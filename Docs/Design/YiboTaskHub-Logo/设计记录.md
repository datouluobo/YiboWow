# YiboTaskHub Logo 设计记录

## 阶段 1：功能语义拆解

状态：已确认。

用户于 2026-10-09 回复“确认”，批准本阶段的主意象、系列结构、配色意向与限制。

日期：2026-10-09。

依据：仓库根目录 `WoW小图标制作工作流.md`、`Logo设计约定.md`、`YiboTaskHub/README.md` 与 `Docs/行动中心-产品与任务模型方案.md`。

- 一句话功能：把账号需求组织为可执行的任务，安排角色并指引下一步行动。
- 推荐主意象：带有醒目推进箭头的任务卷轴，表达“任务安排与行动推进”。
- 必要形状：简化卷轴主体、一体化粗箭头、统一六边形环框；整体控制为 3–4 个主要视觉块。卷轴卷边并入主体，不增加独立装饰。
- 构图意向：卷轴略微斜放，粗箭头朝右上；箭头与卷轴形成一个整体，中心业务符号优先可读。具体比例和角度在阶段 2 探索。
- 系列归属：深青黑六边形环框与一条连续青绿色识别线，继承 YiboCore 结构；外框不压过任务主体。
- 配色意向：暖象牙色卷轴提升暗色 UI 上的可读性，青绿色箭头呼应系列识别色；材质与光效在阶段 5 处理。
- 干扰限制：不加入文字、细小清单行、多角色头像、物品堆、复杂分支网络或场景背景；透明外围延伸至画布边缘。
- 尺寸要求：先在 32×32 网格探索轮廓，并提供 24×24 预览；主体轮廓跨度至少占画布 85%，用粗轮廓与大块明暗保障识别。
- 现有资源：目标插件当前只有 TOC、Namespace 与 README，尚无 Media 目录或专属 Logo。

本阶段只交付语义简报。用户明确确认后，下一阶段制作 8–12 个黑白或双色轮廓候选，逐个给出 24/32px 预览；不提前生成材质图、展示图或正式资源。
