- 账号语言偏好保存于 `YiboCoreDB.settings.language`，自动 / 中文 / 英文，重载后生效；无效值安全归一。
- SavedVariables 恢复后、Core 就绪和业务注册前确定会话语言。内置导航、字段、状态、确认框和静态插件目录统一刷新；保存新偏好不会导致混合语言。

## 静态与发布前检查

```powershell
python Tools/Check-Localization.py --output _NonRelease/Localization/Workspace-Report.md
python Tools/Check-Localization.py --addon YiboCore --strict-core --output _NonRelease/Localization/Core-Report.md
./Tools/Test-LuaSyntax.ps1
lua _NonRelease/Localization/LocaleSpec.lua
lua _NonRelease/Localization/LayoutSpec.lua
lua _NonRelease/EntryBar/EntryBarSpec.lua
python _NonRelease/Localization/CheckerSpec.py
```

工具按正式 TOC 清单扫描，排除注释、非发布文件和语言资源；报告中文硬编码、未知静态 key（Core:Text / 显式 Core.Locale:Get）、缺英文、重复 key、格式参数不一致、静态目录与固定尺寸人工复核位置。仅专业原生别名、输入标点归一与字体测量样本列入 Core 精确例外。英文硬编码、动态 key、跨文件封装调用、动态资源注册、动态拼接及第三方翻译完整度仍需按区域人工审查；词法工具不证明语义正确或视觉通过。

开发默认仅报告。`--strict-core` 用于 Core 专项验证，不默认升级为全仓库门禁。Core 打包脚本会自动生成 `Builds/YiboCore-LocalizationReport.md/.json`，分发前必须查看并处理报告、完成客户端验收；本次没有运行发包或发布操作。

## 插件语言与真实客户端语言的验证边界

当前正式三模式设置已具备插件显示语言覆盖能力，无需另建 Locale Override 开关。`GetLocale()` 表示真实 WoW 客户端语言；`Core.Locale:GetLanguage()` 表示插件当前会话语言，返回 `zh` / `en`，不是 `zhCN` / `enUS`。例如中文客户端选择 English 并重载后，前者仍为 `zhCN`，后者为 `en`。插件不得据此假定 Blizzard API 会返回英文名称。

| 验证方式 | 可以验证 | 仍需补验 |
|---|---|---|
| zhCN 客户端＋正式 English 设置＋重载 | Core 和已迁移业务的英文资源、元数据、布局、公共交互与偏好保存 | 英文客户端原生名称、原生 Tooltip、字体及名称匹配 |
| 非发布 `/ylp en` | Core 文本、布局和缺失资源的快速预览 | 正式保存／重载时序；业务模块级文本不保证动态切换 |
| 真实 enUS 客户端＋auto | 实际客户端语言、原生 API 名称、英文环境字体与运行兼容 | 按插件准备角色和数据，完成业务场景回归 |
| 真实 enUS 客户端＋中文设置＋重载 | 英文环境手动中文、中文字体覆盖及插件／原生文本混合边界 | 实际渲染与交互结果须记录 |

日常开发可先在 zhCN 环境中通过正式 English 设置推进，准备国际服账号和可登录的 enUS 测试环境后补实机验收。一个可登录角色用于加载、报错和基本 UI 冒烟测试；多角色快照、专业、邮件、Boss 锁定及重置需要对应角色、数据和场景，不能由冒烟测试代替。需要时将同一源码目录分别联接到两个客户端 AddOns，保存变量与验收记录按客户端分别管理。

当前仅 Core 已接入，业务插件按 CAP-009 渐进迁移；Core 英文窗口壳不能代表业务文本已英文适配。预览能力不能量化为“95% 已覆盖”，不据此减少真实 enUS 验收或推定英文客户端通过。

## 非发布预览

独立探针目录与 TOC 同名：`_NonRelease/YiboLocaleProbe/`。正式 Core TOC 与打包清单不包含该探针。全工作区 Slash 注册检查确认 `/ylp` 未占用，不添加其它别名。

在目标客户端需要预览时，将此目录以同名目录联接到 `Interface/AddOns/YiboLocaleProbe`，启用探针，运行：

- `/ylp zh`：临时中文预览。
- `/ylp en`：临时英文预览。
- `/ylp reset`：恢复本次正式会话语言。
- `/ylp missing`：列出所有已注册目录缺失的英文资源。

预览优先级高于正式偏好，只改变内存。重载会自然结束预览；语言设置仍显示真实账号偏好。预览重建 Core 页面实例并保留不同语言的实例缓存；业务插件尚未迁移，不保证探针切换其模块级文本。实际三模式验收必须通过正式设置和重载进行。
