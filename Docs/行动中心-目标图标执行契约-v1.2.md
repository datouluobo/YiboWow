# 目标图标执行契约 v1.2

2026-10-10 工作树，未发布；客户端安全点击与悬停交互待验收。

## 所有权与发现

Todo 拥有业务执行定义、采集及完成判断；Task 只呈现点击控件；Core 负责公开能力发现和统一窗口生命周期。Todo 的 action.targets v1.2 新增以下可选方法，Task 经 Core List 检查 major1 / minMinor2 后调用。无提供方、禁用、旧版本或失败时，只保留原查看来源，不影响目标列表。无 Frame、回调或数据库引用跨接口传递。

| 方法 | 输入 | 返回与行为 |
| --- | --- | --- |
| GetClickAction | `{intent}` | 独立纯值 `{attributes,leftTitle,rightTitle,professionAction?}` 或 nil；仅当前角色的明确角色目标，账号范围及其它角色返回 nil |
| AfterClick | `{intent,button}` | 硬件点击后的验证请求；重新校验当前角色与动作，左键专业制作请求原合并采集，不执行受保护动作或提前写完成 |

attributes 限定 type1/item1/macrotext1/type2/macrotext2。业务宏及物品定义由 Todo 的 Actions:Describe 生成，Todo 原图标也复用同一生成器。支持诺米物品使用／选中，以及专业制作一次／打开专业；专业未打开时先打开，与 Todo 原交互一致。农场与其它无直接执行动作的项目继续查看来源。

## 控件和生命周期

工作图标使用24px独立边框 Frame，纹理内缩2px，文字从其后28px起排；安全点击区域与图标共用行 Frame 锚点和数值偏移，文字不嵌入图标纹理。所有具体工作行显示图标，包括无直接执行动作的项目；当前角色的真实目标逐项呈现，不收入待核实汇总。Evaluate 可选返回 display.item／icon，来源事实缺失时只用于图标显示，不推定完成或可执行。

主列表与悬停各自在本次打开期间保留已经显示的完成行，并稳定现有行次序；显示“已完成 · 关闭后移出”，图标变灰，来源允许时保留硬件点击能力。关闭清理临时行记录，下次打开重新依据权威快照筛选。明确移除、暂停、范围／筛选改变不保留旧行；仅在完成证据匹配原周期或单次目标确已完成时保留，不以点击本身推定完成。此记录仅存在于 UI 内存，不进入目标库、HUD 或提醒快照。

安全按钮只锚定到行 Frame，使用列布局提供的数值偏移定位；禁止直接锚定 FontString 或 Texture。主表与悬停使用各自工作列的偏移，不额外推导列宽。客户端反馈确认原 FontString 锚定会直接中断刷新，已修复；受控测试现在拒绝此类锚定，并分别验证两处行 Frame 目标与偏移。

Task 主列表与悬停的具体工作图标使用同一 TaskActions 绑定。汇总行与折叠组没有执行入口。SecureActionButtonTemplate 保留模板 OnClick，仅 Hook PostClick；中键及额外按键禁用安全属性回退。原查看来源按钮保留。

每次可见行复用先清除旧安全属性和来源引用，再重新查询；无数据／注销／不兼容时不显示执行控件。晚注册由现有目标来源通知刷新。战斗中不创建或修改绑定，账号窗口沿用 Core 已有安全战斗隐藏、脱战刷新机制。

动作描述是渲染时的临时快照，不保存为第二份业务数据。点击后等待 Todo 权威采集与既有通知更新；点击本身不是完成证据，目标的观察时间、重置与失效语义沿用原契约。
