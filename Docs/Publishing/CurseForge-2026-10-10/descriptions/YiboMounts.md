# YiboMounts

**Dependencies:** No required Yibo addon. Optional — [YiboCore](https://www.curseforge.com/wow/addons/yibocore) (API v5+) for integrated settings.

## The YiboCore framework

YiboCore is the shared account window, character directory, and settings framework for Yibo addons. It is optional here; this addon works on its own. Add [YiboCore](https://www.curseforge.com/wow/addons/yibocore) for supported settings or integration.

See a mount and quickly check where it comes from, directly in its tooltip.

## What makes it useful

Mount-source hints appear in several game contexts, so players can check acquisition information where they encounter the mount. This addresses a common pain point: players can inspect a mount's source in context instead of leaving the game view to search elsewhere.

## Features

- Mount source information in player and target aura tooltips.
- Mouseover-unit, Mount Journal, and supported chat-link tooltips.
- Source details for bosses, dungeons, vendors, quests, achievements, and events.
- Available difficulty, price, reputation, class, and faction requirements.
- Chinese and English source information; optional Core settings.

## Getting started

Hover a supported mount aura, mounted unit, Mount Journal entry, or mount link. Install YiboCore if you want its integrated settings.

## Requirements and data

Mists of Pandaria Classic; packaged for client 5.5.4. YiboCore is optional. Its integrated settings require API v5 or later.

Coverage depends on the included source data. This release provides tooltip information rather than a full collection planner. Core is optional for the basic tooltips.

# YiboMounts · 坐骑来源

**依赖：** 无必需的 Yibo 插件。弱依赖 — [YiboCore](https://www.curseforge.com/wow/addons/yibocore)（API v5+），用于统一设置。



## YiboCore 框架

YiboCore 为 Yibo 插件提供统一账号窗口、角色目录与设置工作台。本插件基础功能可独立运行；[安装 YiboCore](https://www.curseforge.com/wow/addons/yibocore) 可使用适用的设置或集成。

看到一只坐骑时，直接在提示框里查看获取来源。

## 特点与解决的问题

在光环、单位、坐骑面板或链接上直接查来源和获取条件，少离开当前界面另行搜索。
解决的痛点：无需离开当前游戏界面寻找坐骑来源和限制条件。

## 主要功能

- 玩家及目标坐骑 Buff 提示显示来源。
- 支持鼠标指向单位、坐骑面板和适用聊天链接。
- 来源涵盖首领、副本、商人、任务、成就与活动。
- 按已有资料补充难度、价格、声望、职业与阵营条件。
- 中英双语来源信息，可选接入 Core 设置。

## 开始使用

悬停支持的坐骑 Buff、骑乘单位、坐骑面板条目或坐骑链接即可查看；需要统一设置时可安装 Core。

## 运行需求与数据说明

熊猫人之谜经典版；当前发布包对应 5.5.4 客户端。YiboCore 为可选增强；统一设置需要 API v5 或更新版本。

覆盖范围取决于已收录来源资料。当前版本提供来源提示；完整收藏规划尚不在此发布范围。基础提示无需 Core。
