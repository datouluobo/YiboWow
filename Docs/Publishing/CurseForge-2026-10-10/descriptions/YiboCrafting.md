# YiboCrafting

**Dependencies:** Required — [YiboCore](https://www.curseforge.com/wow/addons/yibocore) (API v6+).

## The YiboCore framework

YiboCore is the shared account window, character directory, and settings framework for Yibo addons. This addon requires [YiboCore](https://www.curseforge.com/wow/addons/yibocore) to provide its account page and shared entry.

Find which characters have learned a listed recipe, using a searchable account directory with explicit learned, unlearned, and unconfirmed states.

## What makes it useful

A fixed recipe directory brings each character's recorded learning state into one account view, with clear cues for learned recipes and observations ready to refresh. Its recipe-first, account-wide comparison helps players quickly find which characters know a recipe, plan profession coverage, and decide which characters to update next.

## Features

- Compare learned, unlearned, and unconfirmed states for entries in the candidate directory.
- Browse recipe candidates across characters or organize them by profession.
- Search recorded recipes and products by name or ID when available.
- Use character, category, and state filters to narrow the list.
- Inspect recipe details and recorded character learning states in YiboCore.

## Getting started

Open each character's own profession window to collect recipes; expand profession categories for useful classification data. Then open the Crafting page from YiboCore.

## Requirements and data

Mists of Pandaria Classic; packaged for client 5.5.4. Requires [YiboCore](https://www.curseforge.com/wow/addons/yibocore), API v6 or later. Keep Core updated together with this addon.

The fixed candidate directory and per-character learning snapshots provide an account-wide recipe overview. Optional TaskHub goals let you add crafting-count targets from recipe names and item-ownership targets from product icons. These actions require YiboCore API v13 or later and a compatible TaskHub release; basic recipe browsing keeps its existing Core requirement.

# YiboCrafting · 专业制造

**依赖：** 强依赖 — [YiboCore](https://www.curseforge.com/wow/addons/yibocore)（API v6+）。



## YiboCore 框架

YiboCore 为 Yibo 插件提供统一账号窗口、角色目录与设置工作台。本插件需要 [YiboCore](https://www.curseforge.com/wow/addons/yibocore) 承载账号页和统一入口。

按固定候选目录查询哪些角色已学会指定配方，并清楚区分已学、未学与待确认状态。

## 特点与解决的问题

固定候选配方目录将账号内各角色的学习状态集中呈现，并清楚标出已学配方和适合更新观测的角色。配方优先的账号级横向核对方式，帮助玩家快速找到已掌握指定配方的角色、安排专业分工，并确定下一步优先更新哪些角色。

## 主要功能

- 对候选目录条目显示已学、未学和待确认状态。
- 按账号配方矩阵或专业分类浏览候选配方。
- 按已记录配方、产物名称或可用 ID 搜索。
- 通过角色、分类与状态筛选缩小范围。
- 在 Core 页面查看配方详情和角色已记录的学习状态。

## 开始使用

登录各角色并打开本人的专业窗口采集配方，展开专业分类以补充分类信息；之后从 Core 打开“专业制造”。

## 运行需求与数据说明

熊猫人之谜经典版；当前发布包对应 5.5.4 客户端。需要 [YiboCore](https://www.curseforge.com/wow/addons/yibocore) API v6 或更新版本，建议与业务插件一起更新。

固定候选目录与逐角色学习状态快照共同提供账号级配方总览。可选 TaskHub 目标支持从配方名称添加制造次数目标，并从产物图标添加持有目标。此功能需要 YiboCore API v13 或更高版本及兼容的 TaskHub；基础配方查询沿用原有 Core 版本要求。
