# YiboLegendary

**Dependencies:** Required — [YiboCore](https://www.curseforge.com/wow/addons/yibocore) (API v5+).

## The YiboCore framework

YiboCore is the shared account window, character directory, and settings framework for Yibo addons. This addon requires [YiboCore](https://www.curseforge.com/wow/addons/yibocore) to provide its account page and shared entry.

Keep track of your legendary cloak questline and supported legendary weapon collection checkpoints across characters.

## What makes it useful

A shared target catalog handles a detailed MoP cloak questline alongside collection routes whose evidence differs by item. This addresses a common pain point: progress across different characters and item routes stays visible without assuming every route has the same evidence.

## Features

- Legendary cloak chapters, quests, objectives, reputation requirements, and next steps.
- Collection routes for Thunderfury, Sulfuras, Thori'dal, and the Warglaives of Azzinoth.
- Supported checkpoints for Val'anyr, Shadowmourne, Dragonwrath, and Fangs of the Father.
- Character eligibility, observed items, and route details in an account overview.
- Compact previews through the Core-managed entry.

## Getting started

Use `/yle`, choose a legendary target, and review each character's recorded progress. Refresh observations on the relevant character as you progress.

## Requirements and data

Mists of Pandaria Classic; packaged for client 5.5.4. Requires [YiboCore](https://www.curseforge.com/wow/addons/yibocore), API v5 or later. Keep Core updated together with this addon.

The cloak has detailed questline tracking; weapon routes have different checkpoint coverage. Historical ownership may need explicit evidence. Catalog-only entries such as Atiesh are not implemented acquisition routes.

# YiboLegendary · 传说之路

**依赖：** 强依赖 — [YiboCore](https://www.curseforge.com/wow/addons/yibocore)（API v5+）。



## YiboCore 框架

YiboCore 为 Yibo 插件提供统一账号窗口、角色目录与设置工作台。本插件需要 [YiboCore](https://www.curseforge.com/wow/addons/yibocore) 承载账号页和统一入口。

跨角色记录传说披风任务线与已支持传说武器路线的收集检查点。

## 特点与解决的问题

把详细任务线与材料/掉落型传说路线统一放在账号目录，同时保留不同路线的证据和覆盖边界。
解决的痛点：让多角色传说目标和不同类型的进度证据能在同一处核对。

## 主要功能

- 传说披风章节、任务、目标、声望门槛与下一步提示。
- 收录风剑、萨弗拉斯、索利达尔和埃辛诺斯战刃收集路线。
- 收录瓦兰奈尔、影之哀伤、巨龙之怒和龙父之牙的适用检查点。
- 在账号视图核对角色适用条件、观测物品与路线详情。
- 通过 Core 管理的入口查看紧凑预览。

## 开始使用

使用 `/yle`，选择传说目标，查看各角色记录；在对应角色推进任务与收集时更新观测。

## 运行需求与数据说明

熊猫人之谜经典版；当前发布包对应 5.5.4 客户端。需要 [YiboCore](https://www.curseforge.com/wow/addons/yibocore) API v5 或更新版本，建议与业务插件一起更新。

披风提供详细任务线追踪，各武器路线的检查点覆盖不同；历史获得可能需要明确证据。埃提耶什等仅目录占位的条目不属于已实现获取路线。
