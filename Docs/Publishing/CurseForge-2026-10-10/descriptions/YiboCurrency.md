# YiboCurrency

**Dependencies:** Required — [YiboCore](https://www.curseforge.com/wow/addons/yibocore) (API v7+). Optional integration — [YiboVault](https://www.curseforge.com/wow/addons/yibovault) supplies recorded inventory locations for item-token counts.

## The YiboCore framework

YiboCore is the shared account window, character directory, and settings framework for Yibo addons. This addon requires [YiboCore](https://www.curseforge.com/wow/addons/yibocore) to provide its account page and shared entry.

Check gold and token balances across your characters before deciding who to play or where to spend them.

## What makes it useful

YiboCurrency brings character balances and item-based tokens into one account matrix, including custom items you register yourself. A clear completeness marker shows when an inventory total is based on partial recorded sources, while optional YiboVault adds personal inventory locations. This source-aware, account-wide view helps players quickly find where their balances are held and plan spending without checking characters one by one.

## Features

- An account matrix of gold, registered currencies, archaeology fragments, and item tokens.
- Support for registered seasonal tokens.
- Add custom item tokens using inventory drag-and-drop or item input.
- Separate main-page visibility and monitored hover projects.
- Optional YiboVault integration adds recorded personal inventory locations for item-token counts.

## Getting started

Use `/ycu` to open the currency page. Choose the columns you need and mark frequently checked items for hover monitoring. Log into characters to refresh balances.

## Requirements and data

Mists of Pandaria Classic; packaged for client 5.5.4. Requires [YiboCore](https://www.curseforge.com/wow/addons/yibocore), API v7 or later. Keep Core updated together with this addon.

Offline balances are snapshots. Incomplete inventory coverage is marked; it is not a claim of a complete bank balance. YiboVault is optional.

# YiboCurrency · 货币管家

**依赖：** 强依赖 — [YiboCore](https://www.curseforge.com/wow/addons/yibocore)（API v7+）。可选联动 — [YiboVault](https://www.curseforge.com/wow/addons/yibovault)，为物品代币统计提供已记录的库存位置。



## YiboCore 框架

YiboCore 为 Yibo 插件提供统一账号窗口、角色目录与设置工作台。本插件需要 [YiboCore](https://www.curseforge.com/wow/addons/yibocore) 承载账号页和统一入口。

集中核对各角色金币和代币余额，方便决定登录哪个角色、在哪里消费。

## 特点与解决的问题

账号矩阵集中展示各角色金币、标准货币、节日代币和自定义物品代币；来源完整度标记帮助判断物品数量来自哪些已记录库存，可选 YiboVault 进一步补充个人库存位置。账号级对照与来源提示让玩家快速找到余额所在角色、安排货币使用，也减少逐个登录检查和手工汇总。

## 主要功能

- 以账号矩阵查看金币、收录货币、考古碎片及物品代币。
- 支持已收录的节日代币。
- 通过背包拖放或物品输入添加自定义物品代币。
- 主页面显示与悬停监控项目分别配置。
- 可选接入 YiboVault，为物品代币统计补充已记录的个人库存来源。

## 开始使用

`/ycu` 打开货币页，选择所需列，并将常查项目加入悬停监控；登录各角色刷新余额。

## 运行需求与数据说明

熊猫人之谜经典版；当前发布包对应 5.5.4 客户端。需要 [YiboCore](https://www.curseforge.com/wow/addons/yibocore) API v7 或更新版本，建议与业务插件一起更新。

离线余额为快照；库存来源覆盖不完整时保留标记，不表示已经统计完整银行。YiboVault 为可选增强。
