# YiboMail

**Dependencies:** Required — [YiboCore](https://www.curseforge.com/wow/addons/yibocore) (API v9+).

## The YiboCore framework

YiboCore is the shared account window, character directory, and settings framework for Yibo addons. This addon requires [YiboCore](https://www.curseforge.com/wow/addons/yibocore) to provide its account page and shared entry.

Manage a busy mailbox with searchable messages, grouped attachments, recipient shortcuts, and configurable sending rules.

## What makes it useful

Searchable inbox and attachment views connect review, guarded bulk collection, recipient tools, and rule-based sending in the native mailbox flow. Once items or categories are assigned to recipients, the rule workspace groups matching items by character and prepares recipient-specific batches sized for the mailbox. Players can review and send each batch in one place, greatly reducing repeated item searches, recipient selection, and attachment setup when moving goods among characters.

## Features

- Mail and attachment views with search, filters, sorting, and collection queues.
- Grouped attachment items and collectable gold, with COD confirmation retained.
- An address book for saved contacts, account characters, recent recipients, friends, and guild members.
- Configurable recipient shortcut slots and item/category sending rules with exclusions.
- Account mailbox browsing, overview, history, expiry reminders, and hover summaries.

## Getting started

Open an in-game mailbox to collect or send mail. Use `/yma` for account browsing. Configure recipients and rules in the mail settings, then review the rule-send workspace before starting.

## Requirements and data

Mists of Pandaria Classic; packaged for client 5.5.4. Requires [YiboCore](https://www.curseforge.com/wow/addons/yibocore), API v9 or later. Keep Core updated together with this addon.

Sending and collection require the current character at an open mailbox. Offline mail is the last successful snapshot; large mailboxes may be only partially visible. Expiry reminders use recorded estimates.

# YiboMail · 邮件助手

**依赖：** 强依赖 — [YiboCore](https://www.curseforge.com/wow/addons/yibocore)（API v9+）。



## YiboCore 框架

YiboCore 为 Yibo 插件提供统一账号窗口、角色目录与设置工作台。本插件需要 [YiboCore](https://www.curseforge.com/wow/addons/yibocore) 承载账号页和统一入口。

用邮件搜索、附件汇总、快捷收件人与规则寄件，整理繁忙邮箱和多个角色的邮件。

## 特点与解决的问题

按物品或分类为收件人建立规则后，规则寄件页会自动汇总命中物品，按收件人整理并按单封附件容量拆分。玩家可集中核对每位角色的寄件内容，再逐封确认发送。常用分配关系保存后，重复转移物资大幅减少查找物品、挑选收件人和手工装填等操作，让多角色物品邮寄管理更省时。

## 主要功能

- 邮件与附件视图提供搜索、筛选、排序和收取队列。
- 汇总附件物品和可收金币，COD 保留原生付款确认。
- 通讯录包含常用、账号角色、最近邮寄、好友与公会成员。
- 可配置快捷寄件格，以及按物品或分类匹配、带排除规则的寄件。
- 账号邮箱浏览、总览、历史、到期提醒与悬停摘要。

## 开始使用

打开游戏邮箱收取或发送邮件；`/yma` 查看账号邮件。先配置收件人与规则，在规则寄件界面核对内容后再启动。

## 运行需求与数据说明

熊猫人之谜经典版；当前发布包对应 5.5.4 客户端。需要 [YiboCore](https://www.curseforge.com/wow/addons/yibocore) API v9 或更新版本，建议与业务插件一起更新。

寄件和收取需要当前角色打开邮箱。离线邮件为最近成功快照，大量邮件可能仅能扫描可见部分；到期提醒依据已记录的估算时间。
