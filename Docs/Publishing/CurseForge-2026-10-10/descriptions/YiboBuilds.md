# YiboBuilds

**Dependencies:** Required — [YiboCore](https://www.curseforge.com/wow/addons/yibocore) (API v10+).

## The YiboCore framework

YiboCore is the shared account window, character directory, and settings framework for Yibo addons. This addon requires [YiboCore](https://www.curseforge.com/wow/addons/yibocore) to provide its account page and shared entry.

Compare your characters' builds and inspect equipment, gems, and enchants from one account workspace.

## What makes it useful

Saved specialization snapshots and a live equipment workbench bring comparison and supported upgrades into one account page. This addresses a common pain point: players can compare saved builds and inspect supported upgrades without rebuilding each character's state manually.

## Features

- Account overview of current and backup specialization snapshots.
- A character workbench with equipment model, talents, and glyphs.
- Separate equipment snapshots for each talent slot.
- Equipment enhancement panels with available gem, enchant, engineering, and profession candidates.
- Current-character gem socketing and supported enhancement actions, plus account hover previews.

## Getting started

Use `/ybb`, select a character and specialization, then click an equipment slot to inspect enhancement options. Log into characters to refresh their observations.

## Requirements and data

Mists of Pandaria Classic; packaged for client 5.5.4. Requires [YiboCore](https://www.curseforge.com/wow/addons/yibocore), API v10 or later. Keep Core updated together with this addon.

Offline builds show saved observations. Equipment changes apply to the current character only and depend on available items, professions, and game interaction requirements.

# YiboBuilds · 角色构筑

**依赖：** 强依赖 — [YiboCore](https://www.curseforge.com/wow/addons/yibocore)（API v10+）。



## YiboCore 框架

YiboCore 为 Yibo 插件提供统一账号窗口、角色目录与设置工作台。本插件需要 [YiboCore](https://www.curseforge.com/wow/addons/yibocore) 承载账号页和统一入口。

在同一个账号工作台查看各角色构筑，核对天赋、雕文、装备、宝石与附魔。

## 特点与解决的问题

构筑快照、装备人偶和实际提升候选集中查看，缩短从发现装备问题到处理的步骤。
解决的痛点：减少逐角色手工记录构筑和在候选装备间反复比对。

## 主要功能

- 账号总览展示当前及备用专精快照。
- 单角色工作台展示装备人偶、天赋与雕文。
- 按天赋槽位分别保存装备快照。
- 装备提升面板列出可用的宝石、附魔、工程及专业候选。
- 支持当前角色镶嵌与适用增强操作，并提供账号悬停预览。

## 开始使用

使用 `/ybb`，选择角色和专精，点击装备格查看提升选项；登录对应角色更新观测数据。

## 运行需求与数据说明

熊猫人之谜经典版；当前发布包对应 5.5.4 客户端。需要 [YiboCore](https://www.curseforge.com/wow/addons/yibocore) API v10 或更新版本，建议与业务插件一起更新。

离线角色显示已保存快照；装备操作仅适用于当前角色，并受实际物品、专业及游戏交互条件限制。
