# YiboReputation

**Dependencies:** Required — [YiboCore](https://www.curseforge.com/wow/addons/yibocore) (API v5+).

## The YiboCore framework

YiboCore is the shared account window, character directory, and settings framework for Yibo addons. This addon requires [YiboCore](https://www.curseforge.com/wow/addons/yibocore) to provide its account page and shared entry.

Compare reputation and friendship progress across your characters from one account view.

## What makes it useful

The full account comparison, current-character tree, and a small user-selected monitoring matrix serve different checks from the same observations. This addresses a common pain point: players can compare account progress and make focused checks without maintaining duplicate views.

## Features

- Browse the current character's reputation tree.
- Compare saved reputation observations across characters.
- Monitor up to ten selected reputations in the account matrix.
- Display friendship progress alongside supported reputation data.
- Use matching account and hover views through YiboCore.

## Getting started

Use `/yrp` to browse reputations and select the ones you want to monitor. Log into other characters to refresh their saved reputation data.

## Requirements and data

Mists of Pandaria Classic; packaged for client 5.5.4. Requires [YiboCore](https://www.curseforge.com/wow/addons/yibocore), API v5 or later. Keep Core updated together with this addon.

Offline progress reflects the latest saved observation. The addon displays progress; it does not automate reputation farming.

# YiboReputation · 声望之路

**依赖：** 强依赖 — [YiboCore](https://www.curseforge.com/wow/addons/yibocore)（API v5+）。



## YiboCore 框架

YiboCore 为 Yibo 插件提供统一账号窗口、角色目录与设置工作台。本插件需要 [YiboCore](https://www.curseforge.com/wow/addons/yibocore) 承载账号页和统一入口。

在一个账号视图比较各角色的声望和友好度进度。

## 特点与解决的问题

既能浏览完整角色对比，也能快速检查当前角色或少数重点声望，不必在多个表面重复采集数据。
解决的痛点：避免为完整对比、当前角色浏览和重点监控重复维护数据视图。

## 主要功能

- 浏览当前角色声望树。
- 跨角色比较已保存的声望观测。
- 在账号矩阵监控最多十项所选声望。
- 展示适用友好度与声望数据。
- 通过 Core 账号页和同数据悬停视图查看。

## 开始使用

使用 `/yrp` 浏览声望并选择监控项目；登录其它角色刷新对应声望资料。

## 运行需求与数据说明

熊猫人之谜经典版；当前发布包对应 5.5.4 客户端。需要 [YiboCore](https://www.curseforge.com/wow/addons/yibocore) API v5 或更新版本，建议与业务插件一起更新。

离线进度反映最近保存的观测。插件展示进度，不自动刷取声望。
