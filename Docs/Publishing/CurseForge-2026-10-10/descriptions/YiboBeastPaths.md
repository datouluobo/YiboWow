# YiboBeastPaths

**Dependencies:** No required Yibo addon. Optional — [YiboCore](https://www.curseforge.com/wow/addons/yibocore) (API v6+) for MoP route-maintenance tools.

## The YiboCore framework

YiboCore is the shared account window, character directory, and settings framework for Yibo addons. It is optional here; this addon works on its own. Add [YiboCore](https://www.curseforge.com/wow/addons/yibocore) for supported settings or integration.

Find the patrol paths of Pandaria's hidden hunter pets directly on the world map and minimap.

## What makes it useful

Route overlays show where to search in the game map itself, with a nearby minimap view for ten included pets. This addresses a common pain point: players can follow route references without leaving the in-game map to look up each location.

## Features

- World-map route overlays and nearby route segments on the minimap.
- Start markers and tooltips with pet and footprint information.
- Ten pets: Stompy, Patrannache, Portent, Bristlespine, Bloodtooth, Hexapos, Rockhide the Immovable, Savage, Glimmer, and Bombyx.
- Toggle routes from the map button or slash command.

## Getting started

Open a supported Pandaria zone map. Use `/ybp` to toggle the overlay, or `/ybp show` and `/ybp hide` for explicit control. Basic route display works without YiboCore.

## Requirements and data

Retail and Mists of Pandaria Classic. YiboCore is optional. Its MoP route-maintenance tools require API v6 or later.

Routes help you search; they do not detect a pet's live location or guarantee a spawn. Retail and MoP Classic use different client entry files. Core is only needed for optional MoP route-maintenance tools.

# YiboBeastPaths · 隐兽寻踪

**依赖：** 无必需的 Yibo 插件。弱依赖 — [YiboCore](https://www.curseforge.com/wow/addons/yibocore)（API v6+），用于 MoP 路线维护工具。



## YiboCore 框架

YiboCore 为 Yibo 插件提供统一账号窗口、角色目录与设置工作台。本插件基础功能可独立运行；[安装 YiboCore](https://www.curseforge.com/wow/addons/yibocore) 可使用适用的设置或集成。

直接在世界地图和小地图查看潘达利亚隐藏猎人宠物的巡逻路线。

## 特点与解决的问题

无需在地图和外部路线资料间反复切换；路线直接叠加在游戏地图，针对十种收录宠物。
解决的痛点：避免频繁在外部路线资料和游戏地图之间来回切换。

## 主要功能

- 世界地图覆盖路线，小地图显示附近局部路段。
- 提供起点标记，以及宠物和脚印信息提示。
- 收录重蹄、帕特兰纳克、噩兆、刺脊、血牙、赫克萨波斯、洛克海德、萨维奇、微光之蛾和邦比。
- 通过地图按钮或命令切换路线显示。

## 开始使用

打开收录路线所在的潘达利亚区域地图。`/ybp` 切换显示，`/ybp show` 和 `/ybp hide` 明确开启或关闭；基础路线显示无需 Core。

## 运行需求与数据说明

正式服与熊猫人之谜经典版。YiboCore 为可选增强；MoP 路线维护工具需要 API v6 或更新版本。

路线用于搜索参考，不检测宠物实时位置，也不保证刷新。正式服与 MoP Classic 使用各自客户端入口；可选 MoP 路线维护工具才需要 Core。
