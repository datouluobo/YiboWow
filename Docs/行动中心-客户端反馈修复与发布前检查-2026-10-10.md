2026-10-10。Core 1.11.0 / API12；TaskHub 0.5.0 / schema4。工作树修改，未发布。依据用户本轮提供的四张游戏截图、明确反馈与仓库源码；截图仅作为修改前证据，不能证明修改后的游戏效果。

## 按钮与数据归属

| 所属 | 当前职责 | 直接修改位置 |
| --- | --- | --- |
| Core | ＋／✓ 按钮创建、外观与悬停生命周期；通用手势、冲突处理、经 Contracts 调用 Task | `YiboCore/UI/BusinessItemActions.lua`；手势设置在 SettingsWorkbench |
| TaskHub | 用户目标、参数编辑、精确身份去重、暂停／移除、复制、定位、展示筛选 | Goals、GoalEditor、GoalContracts、Settings |
| 各业务插件 | 绑定真实业务控件，提供对象、角色与参数；保留原点击；解释资格、进度、完成及重置 | 各插件 GoalTargets 与实际业务页面 |

九个来源均复用 Core 按钮。业务插件的绑定位置会影响按钮落点，但不各自创建另一套添加按钮；`menu=false` 只用于已有同一目标入口的覆盖控件。TaskHub 不创建业务页按钮，也不读业务 SavedVariables。

## 已落实的修复

- 目标管理新增“添加目标”来源选择器；九个来源通过 `action.targets` v1.1 `GetEntry()` 提供标题和业务页面 ID，Task 按 Provider 技术标识排序发现。没有入口方法的旧 v1.0 仍可评估已有目标，不能伪造可用入口。来源页缺安装、晚注册、注销随既有契约发现处理。
- 主标签收为“行动总览 / 目标管理”。既有 Boss 专用编辑器通过目标管理中的“首领目录与批量复制”进入，提供返回按钮，继续写同一目标库；通用添加负责引导到真实业务对象，来源配置仍由来源校验。
- 统一设置工作台“行动中心 → 业务设置”增加“显示其它角色目标”，默认开。关闭不会改变目标、复制范围或业务采集；目标管理只列当前角色及账号范围目标。显式定位到隐藏角色时说明应开启哪项设置。
- AltoBoss 状态变化同时通知 `action.targets` 和既有 `action.todo`，Task 新路径立即失效对应缓存；不再仅依赖最长60秒的兜底。
- Lookup 改为经来源规范化的精确身份匹配，区分难度、完成模式等条件；缺参数不误标为已添加。Boss 旧目录合并键补入重复策略，防止一次目标与周期目标相互吞并。
- 删除矩阵 Bind 时逐格 Lookup；仅悬停时查询当前项目。重复刷新复用同一个菜单及脚本。进度投影不复制完成历史；时效计时器覆盖全部保留范围，只清已到期缓存，不清其它有效来源。
- 来源返回“已完成”但完成证据未知或过期时，仍显示待核实工作，不让目标从待办消失；同样不写入完成历史。
- 制造来源优先使用配方名称与已解析产物名称；离线缺证据继续待核实。空目标库 HUD 提示添加入口。
- 目标管理行按窗口高度分页，页边界禁用；配置保存按钮随字段数量下移；角色下拉每页8项。Boss 专用移除加入确认及 revision 校验。

| --- | --- | --- |
| P0 | 九类来源的 ＋、默认中键、配置组合键；尤其 Builds/Todo 安全按钮，战斗前后与禁用 Task | 原业务左／右键正常，不重复施法／使用，不产生污染或 Lua 错误；未就绪有提示 |
| P0 | Task 与业务页双向添加、暂停、移除、复制；不同难度、一次／周期目标；切号／重载 | 同一目标 ID 与角色，不重复导入；实际来源状态及时更新；移除不改监控 |

## 追加：互斥添加设置与 Todo 状态

Core 设置的窗口页已提供三选一添加方式和两种已加入标记样式，当前图标即时更新。中键／Ctrl＋左键再次取消且保持窗口，右上角按钮模式保持原定位与补参流程；手势模式缺参数临时显示补参按钮。当前角色边框与金色折角可区分，青绿圆点为用户可选样式。

Todo 的每日预计可用现在投影为准备，保留 estimated 置信度与原观察时间；初次未采集继续待核实。专业项目描述由主表与目标查询共享，专业变化继续通过 Core 契约通知清理 Task 派生缓存；制作成功后的零冷却滞后刷新不能覆盖同周期完成证据。当前角色的未知目标仍逐项显示，完成图标按既有规则保留到关闭后移出。

复测顺序：设置三选一与标记切换 → 同角色 Todo／Task 图标对齐及直接点击 → 打开专业后的状态更新 → 成功制作与连续点击 → 关闭再打开 → 次日重置及离线角色。战斗期间切换设置须明确拒绝，Ctrl＋左键不得同时触发制作；普通左键继续原业务动作。新增53项检查通过，实际客户端布局、保护动作和性能采样仍待验证。
