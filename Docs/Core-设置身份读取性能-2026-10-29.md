# Core 设置身份读取性能（2026-10-29）

状态：本轮修复和适用离线回归完成；客户端真实CPU／回收后占用、设置交互与存档恢复待验。当前main，基于已有工作树继续修改，未提交、推送或发布。

## 发现与修复

- `Characters:GetShortNameDuplicates` 原先为每次检查生成所有角色完整副本，即使没有短名或没有重复。现先按身份投影分组，只对实际重复组创建完整隔离副本；公开返回字段、组内顺序及副本可修改语义保持。
- Core设置页的 `AccountView:BuildContext` 原先构建默认完整账号缓存，但设置渲染器不消费业务域，托管插件设置使用另外的host context。现仅对实际Core设置页对象使用身份上下文，业务页面仍保留默认完整上下文。
- 设置短名列表、角色排序／缓存列表及重建自定义顺序只使用身份、等级、登录／注册顺序；对应完整缓存读取迁入既有只读身份缓存。

生产改动仅 `Data/Characters.lua`、`UI/AccountView.lua` 和 `UI/AccountPages/SettingsWorkbench.lua`。没有改变存档结构或重置排序；没有对其它页面默认上下文做全局替换。
