## 验证结果

- 全部加载图仍为 15 插件、373 个 Lua 文件，语法检查 373/373 通过。
- 本轮最终 44 个离线测试进程全部通过，包括原先未通过的 6 项。输出、源码摘要及脚本在 `../_NonRelease/PerformanceAudit20261028/`。
- 路线：30 组移动／旋转／缩放／尺寸变化对比旧渲染器，坐标误差最大约 `8.17e-14`；200 次移动绘制累计临时分配约 25.4 MB → 7.0 MB，足迹世界坐标查询 400 → 0。独立 Lua 模拟中耗时下降；不换算成实际游戏 FPS。
- Core：含 10,000 条无关领域记录的角色，1000 次原生采集没有完整角色复制；第三方采集器完整上下文、入库和返回值隔离通过。
- AltoBoss：10,000 个普通 NPC 战斗事件不增加证据缓存或创建跟踪事件；注册目标容量 512、TTL 清理、死亡释放、有效／过期击杀归属通过。
- Todo：每角色每轮一次专业读取、每次重建一次配方扫描；200 次未变化查询没有新增上述工作。
- Mail：相同附件复用、独立复制隔离、恢复后保留不同附件值，以及真实邮件运行、原生收件箱、发件匹配和工作台回归通过。
- 构建：Core Mists／Retail／Forever、Mail Mists、Vault Mists、Todo Mists、AltoBoss Mists、BeastPaths Universal 共 8 组已登记目标的统一构建校验通过。Mail／Vault Forever 尚无已验证构建 profile，统一构建器正确拒绝；未扩充其发布登记。
- 本地化报告已生成并查看：缺英文、参数不一致均为 0；6 个未知 key 全在未触及的 AutoOpen 集成路径。本轮没有新增玩家文本，诺米复用已有中英文资源。全仓既有硬编码候选没有被记为本次已治理。

## 职责、能力与发行收尾

实际生产改动涉及 Core、AltoBoss、Mail、Todo、Vault、BeastPaths。目标范围：Core 三个现有目标；Mail／Vault 共享文件兼及 Forever 草稿；Todo／AltoBoss 现有 Mists；BeastPaths Mists／Retail。没有新增客户端专用 API、目标分支、TOC、XML 或初始化入口；保持现有加载清单与实际加载名。BeastPaths 沿用已记录维护例外。

本轮完整职责单元为数据采集复制边界、领域提交复制、战斗证据缓存、邮件复制／归档结构、待办快照索引、个人计数身份解析和小地图几何缓存。均保持其现有共享位置和业务归属，不复制目标实现。Core 继续承担通用身份与契约隔离，不吸收业务缓存或规则。

Mail／Todo／Vault 新涉及身份调用复用现有 API13／`character-identity:1`，初始化已有对应能力检查，无并行本地回退；Core 内部优化不提高公开 API 或能力版本。诺米标题继续用 owner 语言资源；设置与页面仍复用 Core 窗口、控件、排序和入口。CAP-007 增量记录已同步。

误目标写库保护、Core 就绪／最低版本检查、单次初始化、SavedVariables 名称、技术名和玩家安装目录没有变更；本轮不把未实测保护或存档恢复标记为新通过。旧文件覆盖仍使用原加载路径，没有增加残留文件参与的链路；干净安装／保留旧文件覆盖后的实际绘制、设置与完整退出恢复仍待客户端复测。无新探针或 Slash 命令。
