## 初始源码联接部署记录

2026-10-18：MoP 与无限测试服共用仓库根目录下的 15 个可运行 Yibo 插件源目录。两个客户端的 `Interface/AddOns/<插件名>` 均为指向 `E:\Development\YiboWow\<插件名>` 的 Windows 目录联接（Junction）。

| 目标 | 当前客户端根目录 |
| --- | --- |
| MoP | `C:\Program Files (x86)\World of Warcraft\_classic_` |
| Forever 无限测试服 | `C:\Program Files (x86)\World of Warcraft\_cn_beta_` |

维护入口为 [Link-ClientAddons.ps1](../Tools/Link-ClientAddons.ps1)，路径保存在 [ClientPaths.psd1](../Tools/ClientPaths.psd1)。无限服路径变更时修改配置中的 `Forever`，然后在仓库根目录运行：

```powershell
.\Tools\Link-ClientAddons.ps1
```

也可临时指定新路径：

```powershell
.\Tools\Link-ClientAddons.ps1 -ForeverPath 'D:\Games\World of Warcraft\新客户端目录'
```

支持 `-WhatIf` 预览；可重复运行，正确联接只检查、不重建。脚本先检查两个客户端和全部同名目标，遇到普通目录或指向其它位置的联接立即停止，不覆盖或删除。路径变更后只在新客户端建立联接，旧位置清理由用户另行确认。

范围为仓库根目录中包含同名默认 TOC 的插件，当前共 15 个；第三方插件、设计资源目录和 `_NonRelease` 探针不在自动联接范围内。MoP 已有探针联接保留。

无限首轮验证另行建立了 `AddOns/YiboForeverProbe` → `_NonRelease/YiboForeverProbe` 同名联接，仅用于无限测试客户端，运行步骤见[探针说明](../_NonRelease/YiboForeverProbe/README.md)。

修改源码后两个客户端直接读取同一份文件。已加载 Lua 通常通过 `/reload` 生效；首次安装、新增加载文件或 TOC 变更后完整退出游戏再进入。两个客户端的 `WTF` 与 SavedVariables 各自独立。
