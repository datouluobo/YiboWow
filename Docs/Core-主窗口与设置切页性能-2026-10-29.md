# Core 主窗口与设置切页性能（2026-10-29）

状态：本轮代码修复及适用离线回归完成；实际客户端切页耗时、焦点／输入法行为与保存恢复待验，未判定可发布。当前main，基于已有工作树继续修改，未提交、推送或发布。

## 本轮范围及发现

本轮只沿主窗口和设置工作台的页面切换链检查：导航点击、ShowPage／ShowSettings／SelectSettingsTarget、上下文、尺寸测量、页面Create／Refresh、失焦保存和导航控件更新。生产改动仅 `UI/AccountView.lua` 与 `UI/AccountPages/SettingsWorkbench.lua`。

### 显式打开设置页重复刷新

窗口已显示设置时，ShowSettings(targetID)先调用SelectSettingsTarget；后者会刷新。随后Toggle("settings")又构建上下文并刷新同一目标。

现提取内部目标校验／设置逻辑，ShowSettings只选择目标，再由Toggle统一渲染一次。公共SelectSettingsTarget仍保留选择并即时刷新语义；非法目标回退、独立设置面板及战斗保护保持。

### 失焦时重复保存与重绘离开中的页面

短名、业务等级过滤和档案过滤输入原先在失焦时无条件执行保存／刷新；没有修改也会触发。回车提交随后失焦会再走一次；带着编辑离开设置时，旧页面隐藏引发失焦回调，又重绘了正在离开的设置页。

现比较实际值／规范化值，未变化时跳过保存和刷新（必要时仍规范显示文本）。成功提交后更新比较基线。真实编辑仍在失焦时保存；只有所属设置目标仍可见时刷新，离开中的旧页不重绘。验证失败提示及原值恢复、Esc撤销保持；不取消玩家未提交的真实编辑。

### 导航位置和文本反复写入

RefreshNavigation原先每次清除并重设所有导航按钮和文字锚点，文字也全部重写。现复用稳定的行位置、缩进和高度，只有几何参数变化才改锚点；标题不同才写文本。高亮、点击目标、颜色、可见性及页面列表仍逐次更新，不缓存整个导航结果。
