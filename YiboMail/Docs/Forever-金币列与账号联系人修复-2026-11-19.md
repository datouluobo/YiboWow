# Forever 金币列与账号联系人修复 — 2026-11-19

## 原因与改动

- Core 角色档案金币列沿用固定宽度，碎银铜币加历史标记时发生省略。现在按当前有效角色的完整格式化金额测量宽度，主表、表头、窗口自然宽度与悬停预览使用同一计算。只调整 money 字段，格式化仍复用 Core ArchiveFields/UITheme。
- Forever 原生完整姓名含空格，邮件地址入口沿用 MoP 的禁止空格规则，导致 Core 公开角色目录中的角色全部被拒绝。Forever 目标显式声明姓名允许空格，共享 Normalize 消费该规则；保留完整姓名、原有地址身份和非法控制符检查，MoP 校验保持。继续复用 Core 公开角色目录与阵营证据，不读取其它插件存档。
