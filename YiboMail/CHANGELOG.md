## 工作树修复 — 2026-10-10

- 收件箱当前筛选结果、附件箱已展示图块对应的来源邮件自动调用 GetInboxText 标为原生已读，并确认 Mail 新邮件提醒；重复刷新不重复读信。隐藏／筛除邮件不处理，收取中暂缓，读信前校验实时邮件身份；失败不确认。NativeInboxSpec 覆盖两种视图、纯文字信及各保护分支；小地图提示消退仍待客户端验收。
- 打开邮箱主动调用 CheckInbox 请求服务器列表；邮箱开放时收到 UPDATE_PENDING_MAIL 也重新请求并扫描。有新邮件但缓存仍为空、或邮件头／附件尚未就绪时，最多补查三次；新扫描代次与关闭邮箱取消旧补查。
- 空列表区分“正在更新邮箱”“邮件读取失败”和真正的筛选空结果，避免 NPC／系统信延迟加载时误报暂无匹配邮件。
- MailRuntimeSpec 新增延迟 NPC 礼物、实时操作校验、到信刷新与有限重试验证；NativeInboxSpec 覆盖加载／失败／空结果文案。客户端连接不可用，游戏内待验收。
- 本次仅修改邮箱扫描与空状态呈现；现有 Core 角色身份、视图和入口调用不变，无公共能力接入变化。

## 1.2.0-api1 — 2026-10-08

### 邮箱扫描与公共服务

- 最低 Core 提高至 1.8.0 / API v9、business-services:1；注册 mail.items v1.0，原 Items API v1 保持兼容。
- 邮箱开启时背包事件合并规则匹配，物品信息只处理等待中的相关 ID；同次匹配／渲染共享角色上下文。
- 附件加载复用 Core ItemResolver；发送前实时身份与附件校验保留。


### 规则管理

- 规则管理右侧使用 Core 纵向滚动区域，滚动条只在内容超出时出现；收件人和规则数量统计固定在列表底部，展开／折叠与文字换行更新滚动范围。
- 大类中的英文名称补齐中文显示，移除作废分类、弹药、箭袋和时光徽章可选项；同一收件人下分类规则显示在指定物品规则上方，同类规则保持原有顺序。
- 无可选子类时，小类下拉显示“无子分类”并禁用；仅有一个真实子类时自动选中并禁用；多个子类时允许选择，禁用控件使用灰色样式。
- 规则管理将“大类”和“子分类”紧凑显示在同一行；选择大类后可展开子分类，重新选择大类会重置子分类。
- 区分“施法材料”（Reagent，ID 5）和“交易材料”（Tradegoods，ID 7），专业材料在交易材料下选择；已有规则的分类 ID 与匹配范围保持不变。
- 分类名称优先读取 C_Item 接口，并在无有效返回或报错时尝试旧接口；客户端未提供子分类时显示明确提示。

### 性能

- 邮箱关闭且无扫描错误时，状态查询不再读取 Core 角色快照；实时或错误判断每次查询只读取一次。

- 邮箱关闭时，规则寄不再因背包更新或物品信息事件扫描背包和重新匹配，避免普通拾取触发重复 Core 角色快照复制。邮箱打开时继续刷新匹配，发送／装填期间的保护保持不变。

依赖：YiboCore **1.8.0 / API v9**、`business-services:1`、`character-name-format:1` 和 `item-picker:2`。公开邮件 API 保持 v1。

- 多物品规则按每个 ID 匹配并检查冲突；规则数据升级为 v2，保留旧单物品记录。旧版插件遇到 v2 会停止规则操作，避免丢失多物品语义。
- 重复添加相同物品与收件人提示“该规则已存在，无需重复添加”；收件人变更继续提供整条规则修改确认。

- 收件箱、历史与规则命中内容支持附件换行和自适应行高；每个物品图标可悬停查看原生物品信息。原生邮箱沿用展开、打开和收取交互。
- 规则寄按收件人合并命中规则，名称与数量共用首行，物品按全宽排列并按需换行；右上角提供整组跳过／恢复，无滚动条时外框填满内容宽度。

- 分别记忆四个邮箱标签；在规则寄页关闭后重新打开或重载界面，恢复规则寄并重新扫描，兼容已有原生页码记录。

## 1.0.0-api1 — 2026-10-07

首个 1.0 稳定版本；YiboMail Public API 保持 v1，依赖 YiboCore API v6。

- 邮箱采用收件箱、附件箱、发件箱、规则寄四个标签，统一尺寸与切换行为。
- 新增规则寄及规则管理，支持指定物品、物品分类、排除项、黑名单、跳过和快捷联系人。
- 同一规则第一次点击装填、第二次点击发送；切换目标先归还全部附件，确认清空后重新装填。
- 发件页面由 YiboMail 统一绘制，包含正文、金额、寄币/到付和按 8＋4 排列的十二个附件格。
- 附件箱每行显示七个图标，邮件期限直接显示天数；精简底部操作并统一对齐。
- 历史记录合并事件与结果，保持单行及全部列同页显示；主题与附件列限制宽度，完整内容可悬停查看。
- 同服角色省略服务器名，物品图标支持悬停信息，金币显示文本金额。
- 兼容当前经典客户端正文控件，修复规则寄装填错误，并保留草稿校验和原生发送确认。

依赖：YiboCore API v6；建议使用 YiboCore 1.6.3 或更新版本。
