# 发件箱通讯录与快捷寄件栏实施验收

日期：2026-10-04。代码实施完成；自动验证通过，游戏内验收待完成。

## 实现范围

- 发布 TOC 新增 `Recipients.lua` 和 `RecipientUI.lua`。前者负责六类候选、地址、独立常用名单与快捷格、好友快照、账号好友缓存和近期记录；后者提供通讯录和右键配置共用的有界的来源菜单与名单子菜单。
- 常用名单不设 16 人上限。快捷格保存于 `quickRecipients[1..16]`，允许空位和重复地址。旧常用名单仅在该字段缺失时导入一次，使用独立记录；无效旧记录保留，在常用来源悬停说明跳过数量。
- 首页依次为常用收件人、账号角色、最近邮寄、角色好友、账号好友、公会；快捷栏右键首项自定义。搜索始终跨六类来源，按地址合并并标记来源后分页；显式服务器筛选作用于全局结果，服务器选择器提供全局匹配结果中的服务器。切换来源保留搜索词，清空后显示所选分类。完整地址在悬停显示，账号好友还显示来源角色与最后成功刷新时间。
- 来源菜单宽度最多 200、名单宽度最多 200、高度最多 360 UI 单位；悬停或点击来源后名单向右展开，屏幕右侧空间不足时向左展开。紧凑顶部搜索与底部操作并排；正常空间来源名单满页 7 行、全局结果满页 8 行，少量名单自然收缩。容量由可用屏幕空间计算，不使用角色数量阈值。行控件复用，翻页不增长控件池。
- 展开名单顶部为搜索与关闭，不显示重复的来源返回按钮；左侧“通讯录”返回来源首页。服务器选择状态使用筛选按钮“返回名单”，底部管理按钮按面板宽度收缩。
- 动态“加入常用 / 移出常用”，移出与清空目标格采用二次点击明确对象确认；地址改变或弹层刷新取消待确认操作。“管理”为灰态占位。
- 快捷栏左键沿用原生填写和发送条件，右键配置不修改当前邮件草稿。Esc 在搜索有内容时先清空，再关闭；外部点击、切换邮箱页面和关闭面板退出配置。
- 游戏好友只采集角色好友接口，不采集 BattleTag/Real ID。每角色保留最后完整名单；未就绪、缺项、异常、枚举期间数量变化时保留该快照。零人仅在收到好友更新事件后的读取接受为空。连续事件由 0.15 秒单次回调合并。
- `friendsByCharacter` 使用规范匹配键到正确拼写完整地址字符串的轻量映射，角色级 `updatedAt`、`status`、`readStatus`。字符串值用于保留显示拼写，每个好友没有详情表；相比规划的布尔成员标记，这是保存大小写所需的实现细化。
- 两个好友分类均排除 Core 完整已知角色目录中的地址（包括当前和隐藏角色，不依赖展示准入）；账号好友进一步排除当前角色完整好友名单。原始快照不裁剪。目录身份集合变化与好友成员变化使派生候选缓存失效，分类人数、搜索和分页使用过滤后结果。
- 账号好友按当前来源 ID 与成员集合版本缓存，在线状态、枚举顺序和刷新时间不重建并集，角色身份集合同时参与缓存校验。排序直接比较已保存地址键。Core 删除及别名补清理覆盖好友独有缓存；ID 迁移选较新的完整快照。
- 最近邮寄仅关联成功发送的捕获地址，去重保留 20 位；失败或未关联发送不更新。当前从新成功发送开始记录。

模型验证覆盖地址及带连字符服务器、去重和显示、迁移幂等、独立槽位、超过 16 位常用名单、好友多来源删除、缓存不变与角色切换、未就绪/部分/空名单、合并回调、Core ID 与别名、近期容量和公会离线条目。

UI 模拟使用真实 Core 主题按钮和实际 NativeUI：右键自定义/来源配置/清空、左键填写及原生发送条件、动态常用确认、全量搜索、筛选分页与控件池、屏幕边界、Esc/外部点击/面板关闭、刷新后过期条目禁止选取。发布装载测试覆盖已清空原生输入后仍使用捕获收件人、失败不记录、好友独有缓存清理。收件箱模拟补齐既有的 `ExpiryColor` 依赖。

独立 Lua 资源采样示例（非 WoW 游戏内测量，计时精度与运行条件会影响结果）：

| 成员关系 | 去重地址 | 快照增量 | 首次并集与排序 | 一次搜索 |
|---|---:|---:|---:|---:|
| 3000（30×100） | 1550 | 约 270 KiB | 约 1–5 ms | 约 0–2 ms |
| 10000（100×100） | 5050 | 约 542 KiB | 约 7–9 ms | 约 3–4 ms |

快照增量取 Lua GC 后存量，未包含整个插件和 UI；测试为相邻角色部分重叠地址。重复并集返回同一有效结果，不重复排序。实际客户端内存和帧耗时仍待测量。
