新增复测：`/reload` 确认 1.0.8，保持全部专业，搜索“灯”、清空、再次搜索数次，停留 20 秒并移动视角；应无持续掉帧。中键魔法灯笼名称应直接添加“制造 1”目标；中键图标应直接添加“持有 1”目标。再次中键同一目标按既有规则取消；目标管理可改数量和范围。无需实际制作昂贵物品。反馈搜索前／后 FPS、是否持续下降、是否出现 Lua 错误，以及目标是否成功保存。

离线证据：SearchPerformance 模拟 6001 条、30 次搜索只读取一个已缓存物品且零加载请求；无关／重复资料事件不刷新，新增匹配名称合并一次。GoalSourcesSpec70 覆盖默认中键直接保存、多产物直接配置、旧 Core 拒绝及中英文资源。语言静态报告已生成并查看，Core 缺英文／未知 key／格式差异均为 0；Crafting 未触及区域仍有旧文本候选，不能按静态引用数量推定区域覆盖。真实中文／英文客户端与手动语言模式验收仍待进行。

## 游戏内验收清单（部分已确认）

不需要重新收集全部目录，也不需要购买昂贵配方。

| 编号 | 操作 | 通过标准 |
|---|---|---|
| G1 | `/reload` 后打开专业制造；在裁缝检查嗜血织焰长裤（产物 75082）和光芒梦境之束（产物 71990） | 与该角色游戏专业面板一致；历史截图中前者已学、后者未学，若期间学习则以当前事实为准 |
| G2 | 在已有的另一专业随意选一条已学、一条确实未学配方，再切换一个已扫描角色 | 当前角色状态正确；离线角色保留自身快照；没扫描的角色为问号。反馈中文名、产物 Item ID、角色及实际状态即可 |
| G3 | 搜索、清空搜索、切分类、滚动和切视图各数次，重复悬停同一配方名称与角色格 | 同一 tooltip 的行动提示只有一条；移出即关闭；图标可悬停查看物品；名称末端按钮可点击，未悬停时不遮内容 |
| G4 | 打开专业窗口后等待约两秒；反复搜索/折叠/展开，然后查看扫描统计 | 普通列表更新不增加查询次数；每次打开窗口允许刷新一次；无持续卡顿或 Lua 错误。若正常游戏中恰好学习配方，页面应自动更新 |
| G5 | 从名称处添加一次，再从同配方角色格添加或定位 | 角色选择明确、已有目标可定位；产物图标与原左键选择保持可用。同步异常记录交由行动中心接入问题处理，不修改学习事实 |

G4 可用以下只读命令查看最近一次查询：

```text
/run local s=YiboCrafting.RecipeStateScanner.lastScan;if s then print(s.state,s.processed,s.batches,s.maxBatchMS,s.elapsedMS) end
```

输出依次为状态、查询条数、批次数、最慢一批毫秒、总毫秒（含批间等待）。以 `complete` 为正常结束。耗时需结合机器和游戏帧率判断；若一批持续达到一帧预算或肉眼卡顿，发布前继续缩小批次或采用时间预算。
