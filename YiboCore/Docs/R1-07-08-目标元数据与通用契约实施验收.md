## 目标元数据与数据所有者

新增`Mists/Metadata.lua`、`Forever/Metadata.lua`，目标清单在Target之后加载。文件只提供本目标业务目录、帮助资源ID、已有实现的说明及清理期望owner；不注册业务插件，不读取业务SavedVariables，不提供业务就绪。重复加载保留同一策略表，目标不匹配拒绝绑定。稳定名称、图标、项目地址和目录渲染仍共享。

| SavedVariables／Interface | YiboCoreDB／50504 | YiboCoreForeverDB／16001 |

AddonCatalog不再在缺目标时默认Mists；缺少明确目标目录策略时目录与期望owner为空。Forever目录和帮助仅使用已实现范围的现有本地化说明，不展示Mists发送邮件、全货币、幻化模型等不适用操作。About继续消费同一目录及AddonStatus，版本索引从目标清单生成；索引版本、安装或注册状态均不代替运行就绪。TaskHub未查得已登记项目地址，目录未虚构链接；本轮仅补其Mists说明，没有新增业务能力或清理owner。

YBP产品元数据补记既有Mists／Retail路线支持；目录文案使用“潘达利亚猎人宠物路线显示”，不登记离线兽栏能力。Core没有Retail清单／目录策略，所以该声明不能在Core中开启Retail目录、身份、窗口或存档。YBP业务运行代码及依赖方式均未改。

清理期望名单从目标策略生成；在此基础上，KnownOwners继续合并当前已注册owner、存档`characterDataOwners`以及删除历史的`requiredOwners`／`acknowledgedOwners`／`failures`中的技术名。历史中存在的目标外owner也保留，不因当前目标目录或插件禁用而丢失。

新删除记录增加可选`requiredOwners`集合，固定当次所需范围；旧记录缺少该字段仍有效，由已有确认／失败信息保守恢复owner。预检只增加可选字段的table形状校验，schema11不变、不迁移或重置存档。未确认owner、回调失败与禁用插件继续pending；晚注册自动重放，确认后不重复调用，失败保留后可显式重试。只有全部已知owner确认且无失败才可按100条软上限裁剪，pending可超过软上限。PruneHistory一次计算owner集合，避免为每条历史重复枚举。

影响说明仍由CharacterCleanup:GetImpact提供给现有缓存删除确认框，按技术名排序；SettingsWorkbench继续复用角色与缓存管理入口，未建立第二份名单或新控件。当前实现中的确认框位于CharacterArchive，不在SettingsWorkbench重复实现，故该文件本轮无运行diff。Core只协调，各业务执行自己的Inspect／Delete。

## 注册、冲突与注销契约核对

保持原接口、API13及能力版本；重复协调由调用方维护初始化状态，不能把以下接口都改成“重复即成功”。本轮只修复下表页面实例生命周期，其余通用实现经审查和适用验证保留。

| 接口 | 重入／冲突 | 注销及调用方职责 |
| --- | --- | --- |
| Registry:Register／RegisterAddon | 同名更新同一注册项的元数据；最低API不满足拒绝 | 无业务插件热卸载接口；注册不代表业务就绪 |
| ClaimResource | 相同kind／id且同owner返回原资源；不同owner拒绝 | ReleaseResource传owner时校验归属，缺资源返回false；调用方应传owner |
| SettingsRegistry | 同owner同ID返回原面板，不应用第二份定义；跨owner冲突拒绝 | Unregister按owner校验并释放资源，重复注销false；GetAll按技术名排序 |
| Events | 相同event／owner／callback去重；新闭包是不同订阅 | Unregister可移除指定回调或owner全部回调；Fire保持异常传播语义，FireIsolated复制普通负载并隔离回调错误；CORE_READY无循环Core对象负载 |
| Contracts Service／Provider | 同方法函数引用、版本和身份返回同ref；方法或minor改变拒绝；同服务／major冲突或kind冲突拒绝；Provider ID带owner前缀 | 注册／注销／变化通知供晚发现；注销校验owner，旧descriptor随即不可用；返回业务结果为副本，不可改内部存储 |
| DataDomains | 域ID重复仍拒绝，包括同owner | 无动态注销接口；生命周期协调一次注册，保持原事件归属 |
| Fields | 静态字段ID重复仍拒绝；必须有合法域／资源／Read | 无动态注销接口；静态定义随清单加载，GetValue只复制所需域数据，不复制全账号 |
| ArchiveFields | 通过Contracts聚合动态字段；重复字段隔离冲突双方并告警，非法快照读为未知 | Provider注销后移出聚合，冲突来源移除后余下有效字段可恢复 |
| CharacterCleanup:RegisterOwner | 同owner重复仍报错；只有Inspect／Delete且业务已注册才接受 | 无热注销接口；下次加载晚注册重放未确认记录，不能通过仅显示已加载owner缩小待清理范围 |
| AccountView:RegisterPage | 重复页ID仍报错，内部页不可注销 | UnregisterPage禁用对应入口、关闭本页活动预览、隐藏并释放实例槽；再次注册同ID执行新Create，重复注销false |
| Entry:RegisterBusinessEntry | 同owner资源协调复用已有入口；跨owner资源冲突拒绝；必须绑定自身已注册页面 | 页面注销禁用入口及交互；LDB对象按既有宿主限制保留并禁用，不承诺从外部宿主销毁对象 |
| Capabilities | 重复注册保留最高版本；Has检查实际最低版本 | 无注销；能力存在不等于Core初始化成功 |
| EntryConfig／CharacterSort／Theme | 稳定共享实现；规范化重复调用保留显式设置；排序只复制索引数组、不改变只读记录；Theme工厂由页面Create协调 | 不为这些工具新增通用注册或Service；入口三通道仍独立，共享窗口／输入／样式不复制成目标实现 |

本轮专项先复现页面问题：注销后重新注册相同ID，旧`frame.instances[id]`仍在，跳过新Create；活动预览也保留旧页面身份。现已在注销时隐藏旧实例、清除该槽并关闭对应预览，新注册执行新的Create／Refresh生命周期。没有改变重复注册错误、保留用户设置或页面资源归属规则。

`Characters:GetAllCached`保持只读共享快照契约：缓存有效时返回同一数组／记录，数据变化由既有失效机制重建。调用方不能修改返回值，也不能要求每次读自动深拷贝。专项验证100次命中仅一次GetAll构建，并核对排序和窗口筛选不改变原缓存；这不是实际客户端帧耗时基准。
