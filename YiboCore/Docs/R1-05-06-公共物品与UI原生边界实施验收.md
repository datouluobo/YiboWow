## 实施与职责边界

| 单元 | 本轮处理 |
| --- | --- |
| 内部 Client | `Runtime/Client.lua`增加幂等、目标一致性校验的surface绑定；`Common/ClientSurface.lua`复用返回值校验与失败语义；`Mists/Surface.lua`、`Forever/Surface.lua`提供原生绑定、物品事件和背包范围。不是新增业务Service或公开能力 |
| 公共物品 | ItemResolver保留ID／链接／名称解析、同ID合并、取消、超时及显式重试；缓存、请求、事件、背包候选查询改用Client。事件订阅失败仍通过有界轮询完成或超时；原生请求抛错立即失败；无效／无限超时恢复8秒默认值，单个异步回调抛错不影响其它消费者 |
| 物品选择 | ItemPicker读取验证后的光标物品ID；只有已捕获且仍相同的光标身份才清除光标。无效／异常读取不清光标、不执行物品操作。组件代次失效、批量原子提交、选择／确认语义不变 |
| UI焦点与位置 | Entry和BusinessItemActions共用现代GetMouseFoci、缺失时才用GetMouseFocus；现代空列表不回退旧焦点，异常结果关闭失效操作菜单。Entry继续使用几何边界判定悬停；拖动遇无效坐标停止，避免nil／非有限数运算 |
| 插件状态 | AddonStatus和AddonCatalog查询走Client，现代启用查询参数为name、character，旧式为character、name；保留注册结果独立判断connected。读取失败增加availability诊断，未连接时state为unavailable，关于页复用既有UNKNOWN_STATUS资源，避免把读取失败说成未安装或已禁用 |
| 宏图标 | 兼容写入bucket及返回table的查询形式，随后才使用已有索引式查询。共享IconPicker仍负责路径归一化、去重及选择；空／失败／部分失败目录不缓存成成功，后续可重试 |
| Popup与战斗 | 既有StaticPopup显示／隐藏及RegisterStateDriver走Client的受控调用；Popup失败取消并清理当前请求，替换后的旧确认不可执行。战斗状态不可读时不授权受保护变更；共享secure隐藏片段及combat条件保持不变 |
| 稳定UI | 审查Theme、Input及AccountView：保持STANDARD_TEXT_FONT、BackdropTemplate、Frame／GameTooltip稳定方法、现有resize新旧方法分支、IME方法选择、几何／滚动预算和布局；不逐个包装稳定帧方法。真实模板、字体、Tooltip、IME与secure执行仍须客户端证据 |

Core只返回公共查询和候选，不新增库存、银行、宠物采集、宠物保存或“已拥有”判断。未修改任何业务插件运行代码；调整的业务目录文件均为离线夹具，显式加载真实Client边界。没有新增消费者接入或提高其最低Core版本。

## 目标与失败语义

| 项目 | Mists | Forever |
| --- | --- | --- |
| 版本／接口／存档 | 1.12.9／API13／Interface50504／YiboCoreDB | 0.2.0／API13／Interface16001／YiboCoreForeverDB |
| 可搜索随身范围 | 0～4；NUM_BAG_SLOTS存在且非4时返回不可用，避免猜测完整范围 | 0～4；仅当本目标Enum.BagIndex.ReagentBag明确报告5时增加5 |
| 物品缓存 | 保持GetItemInfo优先，缺失时C_Item.GetItemInfo | 同左，由本目标绑定提供 |
| 请求与容器 | C_Item请求；缺失时用缓存getter触发；C_Container优先，缺失时旧式容器函数 | 同左；不是Retail能力声明 |
| 加载图 | 61项，含Common/ClientSurface与Mists/Surface | 58项，含Common/ClientSurface与Forever/Surface |

背包范围用于名称候选查询，不是业务库存的完整扫描承诺；不含银行、账号银行或其它角色。任意容器读取异常、非法槽数／物品ID返回失败，不返回部分列表冒充完整结果。显式要求includeBags而读取失败时，Parse返回nil及现有本地化错误，即使已知目录中有候选也不宣称搜索成功。

GetInfo保持ready／unloaded／loading／failed状态形状，追加availability，标识known／unloaded／error／unavailable；只有验证后的缓存名称才ready。缺缓存不会被当成不存在；秘密值及非法类型不进入字符串／数值处理。Finish只允许成功事件且实际缓存就绪时完成成功。未订阅到事件时的轮询不改变公开Request契约。公开基础版本仍为API13，basic-input:1、item-resolver:1、item-picker:1及其它既有能力版本保持；两端各33项能力、并集34项，不借内部封装增加Retail能力。

## 入口、覆盖与公共能力收尾

- 适用插件为YiboCore，目标仅Mists／Forever；源默认`YiboCore.toc`只加载Hint；实际目标源码清单为`YiboCore_Mists.toc`／`YiboCore_Forever.toc`，玩家包仍输出选定内容为`YiboCore.toc`。新surface先于ItemResolver、目录与UI消费者加载，Lifecycle继续最后加载。
- 保留既有真实客户端身份前置校验、初始化幂等、候选存档预检及提交后单次CORE_READY；共享改造不改变业务消费者的Core就绪、API13及能力最低版本检查。Registry connected仅代表注册，不代替业务就绪。
- 技术名、安装目录、schema11及上述SavedVariables身份保持；未跨目标导入、未新增迁移或重置。虚拟覆盖保留R0全部旧文件，当前加载图不引用残留旧采集器；新增文件没有旧路径冲突。实际干净包／覆盖包及WTF恢复待验。
- 构建引用由TOC自动闭合，统一构建ValidateOnly核对目标、Interface、引用及源码；未增加Retail清单／构建目标。库及媒体资源不变。
- CAP-002／003／004适用公共实现与API文档补充；CAP-009复用现有资源。能力迁移台账只记Core实现与证据，不把YBP或其它消费者记为新接入。后续业务修改触及同类调用时继续消费既有Core公开能力，不直接使用内部Client。
