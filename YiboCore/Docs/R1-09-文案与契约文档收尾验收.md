## 文案收尾

新增6个稳定ASCII key，中文／英文资源一一对应；没有移除旧key、改写动态原生名称或业务／玩家历史数据。

| key | 本轮行为 |
| --- | --- |
| CORE.ITEM_BAG_SEARCH_UNAVAILABLE | 名称查询要求includeBags而背包读取失败时，提示随身背包暂不可读，不再沿用物品缓存加载失败提示；仍返回nil及本地化消息，不提交部分候选 |
| CORE.ADDON_STATUS_UNAVAILABLE | About状态读取失败时显示明确不可用，不把未知信息当成未安装；版本区域也使用该提示 |
| CORE.ADDON_VERSION_UNAVAILABLE | 已确认安装、但没有可用版本字符串时，显示版本暂不可用 |
| CORE.ADDON_INSTALLED_VERSION | 安装版本作为完整文本以%s插值；保留v前缀及原生版本值 |
| CORE.ADDON_PACKAGED_VERSION | 打包时版本作为完整文本以%s插值，与安装版本来源明确分开 |
| CORE.ADDON_REGISTERED | About将connected显示为“已向Core注册”，不暗示业务就绪；公开状态值仍是connected |

本轮仅修改`Runtime/ItemResolver.lua`、`UI/AccountPages/About.lua`及中英文资源4个运行文件。About状态／版本整个区域统一使用会话资源；共享布局、控件、目标绑定、初始化、注册、存档结构和能力版本均未修改。ItemResolver返回形状与异步契约保持，错误文字只用于展示，消费方不能用本地化消息匹配业务状态。

人工审查了R1启动、目标／存档保护、数据域失败保留、目标目录／帮助和清理owner资源：新增提示已有双语完整文本，格式参数一致；目标元数据使用稳定资源ID。核心启动前尚未信任账号偏好时按客户端语言提示；成功初始化后固定会话语言，手动偏好重载后生效。Core默认Hint发生在语言服务前，继续保留原独立双语提示；26个专业名称别名用于原生匹配，不重译或用于新业务身份。

新增[API13共享底座兼容与失败契约](API-v13-R1共享底座兼容与失败契约.md)，集中说明职责、实际公开入口、最低能力、输入输出、失败与缺失、角色／账号范围、快照时间、重入／冲突／注销和目标／验收边界。明确Core.Client为内部实现，Core不接管业务存档、宠物采集或“已拥有”判断。
