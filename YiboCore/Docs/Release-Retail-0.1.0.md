# YiboCore Retail 0.1.0 / API13

Retail 客户端：12.1.5，Interface 120105。安装目录：YiboCore；存档：YiboCoreRetailDB，与其它客户端独立。

提供角色目录、账号视图、统一设置、入口及公开API13基础设施。YiboBeastPaths v1.8.2路线继续独立运行；配套开发修订版1.8.3接入Retail与Mists的Core维护设置和现有维护页面，两端新存档默认显示该页面。后续离线兽栏所需公共接口已有契约验证，实际离线兽栏功能由后续YBP版本提供。

下载Retail安装包并解压到正式服Interface/AddOns，保持YiboCore目录一层。使用单一更新来源；GitHub全目标源码归档用于开发查阅。已有开发版用户保留WTF存档，正常覆盖代码即可；不要向仓库源码联接解压。

已验范围：12.1.5/70575、zhCN，指定包干净安装、R2开发包覆盖、基本页面、重复初始化、reload及完整退出设置恢复。其它客户端目标分别记录验收状态。

发行状态与最后同启验收见本轮发布记录；本说明本身不表示已经上传。

## English

Retail 12.1.5, Interface 120105. Install folder: YiboCore. Retail data uses YiboCoreRetailDB independently of other clients.

Provides character directories, account views, shared settings, entries and API13 infrastructure. YiboBeastPaths v1.8.2 routes remain independent; development revision 1.8.3 adds Core maintenance settings and pages on Retail and Mists, visible by default for new profiles. Offline pet viewing is planned for a later YBP version.

Extract the Retail player package into Interface/AddOns. Keep WTF data when updating, and use one update source per addon directory. GitHub source archives are intended for development.
