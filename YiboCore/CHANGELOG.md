# YiboCore 更新日志

## 1.2.0

- 重构统一设置工作台：角色过滤收口至“角色与排序”；Core 与业务插件的页面、入口和字段集中至“显示与入口”。
- 新增 Core 入口四态模式与共享入口下拉菜单；关闭 Core Broker 不再影响业务插件的独立 Broker 入口。
- 新增插件目录、运行时安装/启用/连接状态，以及发布包内生成的子插件版本清单。
- 数据库 Schema 升至 v9，并兼容迁移既有 Broker 与小地图入口设置。

## 1.1.1

- 当前角色改用统一的强调描边标识，保留账号表原有的状态色和斑马纹可读性。
- 为业务账号页面提供共享的当前角色描边主题辅助函数。

## 1.1

- 升级统一账号视图的矩阵尺寸与角色列分页：完整角色列优先扩展至屏幕安全边界，再启用分页。
- 压缩账号视图、表格与悬停预览的共享间距；分页控件移至窗口标题栏，避免挤占业务数据列。
- 改进服务器范围选择器、滚动条状态和业务设置页切换时的控件清理。
- 发布脚本改为先构建临时包，成功后归档旧 Core 包再原子替换，避免打包失败时丢失旧包。

## 0.6.0

- Public API 升至 v5，数据库 Schema 升至 v7；v4 页面、入口和角色档案 API 在 0.6.x 继续可用。
- 新增数据领域注册与领域存储：身份、经济、声望、专业、装备、地点和专精按各自事件采集，并独立保存状态、更新时间、schema 版本与 revision。
- 新增 `DATA_DOMAIN_UPDATED` 数据变化协议；旧 `CHARACTER_PROFILE_UPDATED` 由兼容适配器继续提供。
- `Profile:RefreshCurrent()` 收缩为领域调度与旧采集器适配，不再直接耦合 Core 中性事实的采集实现。
- 新增资源与字段注册表；角色档案和悬停投影从注册字段自动生成，旧字段设置会映射到稳定的 `character.*` ID。

## 0.5.0

- 统一 Core 大小 Logo：小图采用高辨识度的六边形环核，大图保留可扩展的机械面板细节。
- 关于页的 Core 与系列插件 Logo 统一提升至 72px，首页标题直接显示当前版本号。

- 数据库 Schema 升至 v6，新增跨插件缓存角色删除协调记录。
- Core 角色档案支持逐个删除离线角色缓存，并同步清理身份、档案、别名、隐藏和自定义排序引用。
- 新增角色数据所有者契约、未加载插件延迟重试和 legacy 缓存防复活检查。
- 当前登录角色受到 UI 与数据层双重删除保护；删除明确不可撤销且不影响账号共享数据。
- 统一角色排序改为结构化设置，支持真正按最后登录时间排序、名称、等级和账号自定义顺序。
- 新增通用默认排序与业务页面独立覆盖、升降序和当前角色置顶。
- 主窗口、业务摘要与悬停预览统一在业务准入后排序，预览从同一结果截取前 20 名角色。
- 数据库 Schema 升至 v5；旧 `seen` 顺序迁移为自定义顺序，避免升级后角色排列突变。
- 角色临时 ID 升级为正式 GUID 时同步迁移自定义顺序和隐藏状态。

## 0.4.0

- Core API 升至 v4，新增由角色目录与业务快照准入共同派生的服务器范围模式。
- 服务器范围在每次构建页面与悬停预览时动态生成，当前服务器置首，随后为其它有业务快照的服务器与“所有服务器”。
- 业务插件不再复制或保存服务器清单，只需声明 `scope.mode = "realms"` 与 `HasCharacterSnapshot(character)`。

## 0.3.1

- 补充业务页面角色准入回调与页面范围 `scope` context。
- 统一页面、入口、Broker 与小地图资源的注册、冲突诊断和生命周期。
- 落地统一账号视图预览投影、概览行动预算、设置入口及 Core-only 回归清单。

## 0.3.0

- 引入 API v3 与多插件统一入口、账号视图协作协议。
- 保持 v2 调用在兼容期内可用。
