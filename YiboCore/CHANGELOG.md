# YiboCore 更新日志

## 1.11.0 / API v12 — 未发布（2026-10-10）

主动添加菜单的已加入勾选改用 WoW 原生纹理，避免中文客户端字体缺少✓字符时显示空方块；未加入仍显示 ASCII ＋，金色折角与手势保持原行为。

新增 business-item-actions:1、可配全局手势与统一项目菜单；复用公开 Contracts，不承接业务数据。契约及客户端待验收项见 Docs/API-v12-业务项目主动添加.md。

项目 ＋／✓ 改为悬停显示并位于控件内部；Bind 不逐格查询 Task，悬停时才经规范化身份查询当前目标；项目与菜单间移动保留入口，离开后关闭。新增行为仍要求 API12 / business-item-actions:1。

已加入项目常驻金黄色折角，由 action.demands v1.1 批量查询并按帧合并刷新；悬停说明目标数量和状态。添加手势保持主窗口与悬停，再次手势取消对应目标且不导航，缺参数提示点＋补充；显式菜单保留配置与定位。

- 新增 account-surface-budget:1：在页面尺寸测量前提供扣除窗口壳及安全边界的 surfaceAvailableHeight，悬停同时考虑入口上下空间。TaskHub 0.2.1 用最终压缩行数申请高度，契约见 [视图可用高度](Docs/API-v11-视图可用高度.md)；保持既有页面接口兼容。

- ContractsSpec 90 项、现有服务与名称回归通过；名称测试改为拒绝 API_VERSION+1，保留 v10 兼容覆盖。
- Todo 两项任务输出、TaskHub 主页面和 O4 展示已接入；原集成 133 项及新增展示 86 项通过，0.1.1 主页面外观获用户确认，新增客户端行为待验收。Core 仍不接管业务判断。契约见 `Docs/API-v11-跨业务Provider.md`。
