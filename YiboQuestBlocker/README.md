# YiboQuestBlocker

魔兽世界怀旧服 熊猫人之谜（5.5.4）任务拒绝管理插件。

当前版本：`v3.0.0`

它的目标很简单：当你启用了自动接任务类插件后，依然可以把不想接的任务加入拒绝列表，并在接取前自动拦截。

## 功能

- 接取前直接拒绝已屏蔽任务（不进入任务日志）
- 支持全局拒绝和角色独立拒绝
- 网格界面管理任务与角色
- 支持当前任务直接勾选加入拒绝
- 支持手动输入任务 ID 添加拒绝
- 支持手动执行“放弃已拒绝”，并带有倒计时确认
- 自动放弃队列作为直接拒绝被绕过时的兜底
- 已知自动接任务插件的运行时检测、有限诊断与安全降级
- 支持聊天提示开关
- 支持按等级过滤角色显示
- 支持等级表达式过滤
- 支持按名称、等级、拒绝数、自定义顺序排序角色列
- 支持右侧小窗口调整角色自定义顺序
- 支持调整角色表头每行字数
- 由 YiboCore 统一管理账号页、Broker 与可选小地图入口
- Broker / 小地图悬停显示与账号页一致的任务屏蔽预览

## 适用版本

- WoW MoP Classic / 国服 5.5.4

## 命令

- `/yqb`

## 使用方式

1. 使用 `/yqb` 或 YiboCore 账号视图打开“任务屏蔽”页。
2. 在“当前任务列表”里直接勾选任务，加入全局或角色拒绝。
3. 如需静默使用，可关闭“聊天提示”。
4. 默认会在接取前直接拒绝已屏蔽任务；无法阻止的特殊路径可开启“自动放弃”作为兜底。
5. 如需手动处理当前日志中的已拒绝任务，可点击底部“放弃已拒绝”按钮，倒计时结束后执行。
6. 已加入拒绝的任务会出现在“拒绝组”里，可随时取消。
7. 如需手动添加，输入任务 ID 后选择“当前角色”或“全局”，再点“添加”。
8. 如需调整角色列顺序，把排序切到“自定义”或保持当前自定义顺序，点“调整”后在右侧窗口中上下移动角色。
9. 如需压缩或展开角色列表表头，可在右侧顺序窗口里调节“表头每行字数”。

## 过滤规则

- `日常`：包含日常、周常、月常以及可重复任务
- `普通`：非重复类普通任务
- `隐藏完成`：隐藏当前已完成任务
- `等级过滤`：支持 `90`、`1-20`、`<=3`、`>=85`、`<=3,89,90` 这类表达式

说明：
等级过滤使用英文逗号分隔多个条件；输入 `0` 或留空表示不过滤等级。
四风谷农场“产品订单”类任务在本插件中按日常组处理，便于统一过滤。
安装 Questie 后，插件可以借助其任务数据进一步提高过滤器的分类精度。

## 数据说明

插件使用账号共享的 `SavedVariables`：

`WTF\Account\<账号>\SavedVariables\YiboQuestBlocker.lua`

文件内保存的变量名为 `YiboQuestBlockerDB`。
已知角色、拒绝列表和筛选、排序偏好都会保存在这里。
`v1.1.0` 起，窗口尺寸、过滤设置和角色表头显示参数也会一并持久化。
`v1.1.1` 修复了游戏小更新后自动放弃失效的问题。
接入 YiboCore 后，独立入口的显示模式、位置与悬停预览由 Core 保存；业务数据和筛选偏好仍保存在本插件存档中。

## 安装

将插件目录放入：

`World of Warcraft\_classic_\Interface\AddOns\YiboQuestBlocker`

## 已知限制

- 角色选择界面的真实显示顺序无法直接从游戏内 API 读取，因此使用插件内自定义顺序替代。
- 任务分类主要依赖游戏任务日志与 Questie 数据兜底；极少数特殊任务如遇异常，可继续补充规则。
- 自动放弃仍受游戏 API 限制影响，部分任务即使进入日志也可能暂时无法放弃，插件会跳过并提示。
- 为避免改变第三方插件的候选规则，未验证的自动接任务插件不会由 YQB 替它选择下一任务。
