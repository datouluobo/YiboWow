# YiboQuestBlocker 更新日志

## 2.0

- 修正任务矩阵内容宽度与“全局”列绘制宽度不一致，避免最后一个角色列右侧多出空白。
- 统一中英文角色名表头为单行固定宽度，将当前服务器角色列增至 72px；主窗口行底色铺满可视区，悬停保持按内容紧凑显示。
- 修正悬停预览右侧尺寸契约：为滚动条保留独立 16px 槽位，避免最右角色列被裁切或被滚动条覆盖。
- 接入 YiboCore 单角色缓存删除契约，只清理目标角色的个人拒绝列表与任务名缓存。
- 全局拒绝任务、全局任务名缓存和插件设置不会随角色删除。

- 角色身份、服务器、职业、等级和账号顺序全面改由 YiboCore 角色目录提供
- 角色任务快照改为按 Core `characterID` 存储，不再使用 `服务器-角色名` 或 `角色名-服务器` 键
- 首次升级将现有角色屏蔽数据转入 `characterData[characterID]`，随后删除 v1 的 `knownChars`、`perChar` 与 `customCharOrder`
- 服务器范围由 Core 根据角色目录和 QuestBlocker 快照准入动态生成，主界面与悬停共用
- 移除 v1 运行时键解析、角色导入和临时诊断逻辑

## 1.2.2

- 完整接入 YiboCore：注册“任务屏蔽”账号页面和可选业务入口
- Broker、小地图入口、悬停账号预览及入口位置统一由 YiboCore 创建和保存
- 移除 QuestBlocker 自建入口依赖与旧小地图位置写入；`/yqb` 改为打开 Core 页面

## 1.2.1

- 抽离可复用的 Broker / LibDBIcon / fallback 小地图入口模块
- 保持 `YiboQuestBlocker` 现有点击、悬停临时展开与拖拽定位行为不变
- 为后续在 `YiboAltoBoss` 等插件中直接复用入口源码做准备

## 1.2.0

围绕 Broker 生态兼容做的一次入口增强更新。

### 新增

- 新增 `LibDataBroker-1.1` launcher 支持，可被常见 Broker 面板识别
- 新增 `LibDBIcon-1.0` 小地图图标支持
- 新增账号级 `minimap` 配置区，用于保存 Broker 图标状态与位置

### 兼容

- 缺少 Broker 相关库时，自动回退到插件内置手写小地图按钮
- 旧版本保存在角色数据里的 `minimapPos` 会作为新图标配置的初始位置来源

### 交互

- Broker 图标与内置小地图图标统一支持悬停临时展开主窗口
- 悬停展开的主窗口会贴着图标下方出现，便于直接把鼠标移入窗口操作
- 左键点击打开的主窗口与悬停临时展开的主窗口状态已拆分，避免移出时误关正式打开的窗口

## 1.1.1

围绕游戏小幅更新后的自动放弃兼容性做的一次修复更新。

### 修复

- 修正自动放弃流程在最新游戏小更新后失效的问题
- 自动放弃前的可放弃判断改为更稳妥的任务 ID 路径，减少日志索引变化带来的兼容性问题
- 统一手动放弃与自动放弃的执行流程，避免两条路径行为不一致
- 放弃确认弹窗改为扫描当前可见确认框，提升兼容性

## 1.1.0

围绕“已拒绝任务的后续处理”和“界面过滤可用性”做的一次增强更新。

### 新增

- 新增 `聊天提示` 开关，可控制插件是否在聊天框输出状态提示
- 新增 `自动放弃` 开关，可把已拒绝且已经进入任务日志的任务加入自动放弃队列
- 新增自动放弃队列与延迟处理逻辑，避免在任务对话仍打开时立即执行放弃
- 新增角色表头每行字数调节，可在右侧顺序窗口中修改显示密度
- 新增当前任务列表总数统计，显示为“可见数量/总数量”

### 界面

- 等级过滤从旧的最小值/最大值切换为表达式输入
- 等级过滤支持 `90`、`1-20`、`<=3`、`>=85` 以及英文逗号分隔的多条件组合
- 等级过滤输入框在格式错误时会高亮提示
- “放弃已拒绝”按钮增加 3 秒倒计时，降低误触概率
- 右侧角色顺序窗口支持显示更多角色项，并补充空状态与非自定义排序提示
- 主窗口尺寸和角色表头显示设置改为持久化保存
- 刷新界面时会主动同步过滤复选框状态，减少显示与配置不一致的问题

### 行为调整

- 已拒绝任务在启用自动放弃时，会先进入队列，再按条件自动执行放弃
- 自动放弃前会检查任务是否仍在日志中，以及该任务当前是否允许放弃
- 对当前任务列表的“隐藏完成”过滤改为真正受开关控制
- 当前任务刷新逻辑增加节流，减少重复扫描任务日志
- 聊天提示统一走可开关的输出路径，便于静默使用

### 兼容与数据迁移

- 旧版本的等级过滤配置会自动迁移到新的表达式格式
- 旧版本保存在角色数据里的窗口尺寸会自动迁移到新的 UI 配置区域
- 新增 UI 配置存储区，用于保存窗口尺寸和角色表头显示参数

## 1.0.0

首个公开版本。

### 新增

- 任务自动拦截功能
- 全局拒绝与角色独立拒绝
- 主界面网格管理
- 当前任务列表快速加入拒绝
- 手动输入任务 ID 添加拒绝
- “放弃已拒绝”按钮
- 小地图图标
- `/yqb` 与 `/yiboquestblocker` 命令
- 角色列等级过滤
- 角色列自定义排序
- 右侧角色顺序调整窗口

### 界面

- 主界面重构为更紧凑的深色风格
- 标题栏加入插件图标和版本号
- 角色名按职业颜色显示
- 滚动条、折叠箭头、过滤区交互细节优化

### 任务过滤

- 日常/普通/完成状态过滤
- 对日常、周常、月常、可重复任务统一归入“日常”过滤组
- 修正四风谷农场“产品订单”类任务被误判为普通任务的问题

### 行为调整

- 默认静默启动，进游戏不自动弹出主界面
- 小地图图标或斜杠命令手动打开主界面
- 加入拒绝不再自动放弃当前任务，改为手动执行“放弃已拒绝”以避免误操作
- 修正 `/reload` 后拒绝数据未正确读回的问题
