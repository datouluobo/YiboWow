# 离线兽栏主窗口：已选设计方向

2026-11-14：用户选定本轮第 2 张「外观索引」作为主布局，并结合第 1 张「外观兽栏」的右侧详情栏。**当前效果图为组合 v2：随身宠物与兽栏同页分区，非标签切换；运行实现与验证进行中。** v1 将两者做成标签页，已被用户要求调整，不再作为目标。用户随后要求在详情增加来源地图；实际数据来源及验证范围见[重构记录](1.9-离线兽栏主窗口重构-20261114.md)。

- 主要任务是找宠：宠物图标经常相同，主窗口须优先展示能辨认体型、毛色的实际全身外观，名称、家族、等级作为辅助。
- 尽量保持兽栏感：随身宠物作为顶部展示条，兽栏记录在下方同页连续浏览；不得拆成互斥标签页。原始槽位位置及各组记录时间明确；家族索引、搜索和分组浏览参考第 2 张。空间不足时，家族索引可改为“宠物分类”下拉。
- 选中宠物后，右侧固定详情栏参考第 1 张，显示选中宠物外观及记录内信息；不可提供离线移动、召唤、放生等操作。
- 使用 Core 的统一窗口、角色范围、设置及入口。只读展示已有记录，未知和历史状态保留，不把未确认观察当作完整库存。
- 图内宠物为生成示意，名称、家族、毛色等并非游戏事实；实际模型／外观标识采集、离线恢复、性能和跨目标可用性须另行核验，不以效果图认定实现可行或验收通过。
