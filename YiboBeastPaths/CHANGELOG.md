# YiboBeastPaths 更新日志

## 1.8.2 — 桑蚕路线与参考资料优化（2026-10-28）

- 修正桑蚕及“啃过的柔丝草”名称，更新宠物参考图并新增并排显示的柔丝草图片。
- 更新桑蚕路线位置、比例和起点，将 28 个实测采集点的融合结果固化为最终路线；玩家初始脚印表保持为空。
- 修复世界地图脚印标记显示与融合坐标转换。
- 整理 1.9 离线兽栏开发方案与验收任务；该功能仍处于开发准备阶段。

## 1.8 — 小地图移动平滑与 Core API13（2026-10-14）

- 小地图路线位置刷新提升到 60Hz（约 16.67ms）；451% 飞行速度下已由玩家实测，视觉跟随平滑。
- Core 维护区域沿用 1.7.0 的 API13、会话语言与公共多行输入适配；Core 1.12.1 基线，缺失所需能力时只停用维护增强。
- 更新系列插件图标并迁入 Media；发行包保留当前图标，CurseForge 安装包排除 Media/vN 历史素材。
- Core 维护页的中英文完整客户端验收仍待完成。

## 1.7.0 — Core API13 适配（2026-10-13，客户端待验收）

- 固定 Core 1.12.1 / API13 基线，维护增强检查语言、基础输入、账号页面和页面可用高度能力及实际使用方法；Core 缺失或不兼容时保留独立路线显示。
- 维护页与统一业务设置使用自有中英文资源，通过 Core 会话语言显示；地图开关与命令提示共用资源，独立模式按客户端语言显示。
- 多行导出输入复用 Core CreateInput，保持不限长度、换行、复制和焦点清理。
- 支持 CORE_READY 晚就绪注册，重复初始化不重复注册；页面注册失败恢复关闭状态，关闭维护页取消焦点和待确认动作。
- 维护页按可用高度提供窗口尺寸，说明文本随换行增加高度；只保留三字母主命令 `/ybp`。
- 自动化与语法检查通过；中英文客户端、手动语言模式及游戏内交互仍待验收。
