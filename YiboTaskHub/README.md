主表来源下拉与状态筛选用于快速找工作；多条待核实观察按角色、来源及受益者折叠，点击展开／收起原始明细，账号数量不减少。悬停先覆盖各角色摘要，仅当前角色展开明细；空间不足时显示部分明细并在底部说明剩余项，其余角色始终保留摘要。工作图标复用来源元数据和 Core ItemResolver，详情保留完整身份与观察时间。HUD“列表”和登录弹出列表恢复全服、全部来源／状态及第一页，避免旧筛选挡住当前角色工作。

设置工作台 → 行动中心 → “行动中心显示内容”可按来源、各项冷却／日常控制显示，同时影响主列表、悬停和提醒。Todo 提供完整的受支持项目目录，尚未采集的冷却也能提前隐藏；恢复来源总开关会保留各项目的独立选择。角色显隐通过“角色与排序”直达 Core 的唯一入口；“待办监控”打开 Todo 的监控设置，控制是否跟踪。行动中心的显隐开关只保存展示偏好，不修改来源监控、完成记录或刷取目标。列表按来源筛选并分页，来源暂时离线时仍可恢复已隐藏项目。

默认显示当前角色常驻面板，每次登录发一次轻量摘要；新增工作在面板标记。Core“行动中心 → 业务设置”配置显隐、锁定、容量和提醒模式，面板标题可拖动。“显示与入口”选择行动中心预览或启用独立入口，并调整主表／悬停字段。悬停默认最多 20 名有效角色；空间不足压缩为角色摘要，悬停行查看明细，剩余角色明确提示到主窗口查看。

诺米复用账号待办的监控设置与资格判断，来源筛选选择“诺米日常”。目标完成仍显示“待交付”，交付后移出；次日已确认持续资格的角色恢复“可接取”，没有资格依据的角色保持“待核实”。

O5 当前来源为“新邮件”，每角色最多一条查看提醒；查看信件或展开附件后停止提示，附件可留在邮箱备用。升级前缓存建立基线，邮箱外原生到信先提示查看，扫描后细化数量。诺米与神纹布继续独立输出；其它任务所需邮件附件留待真实需求契约接入，不从库存推断必须收取。详见 [新邮件语义与角色显示复核](../Docs/行动中心-新邮件语义与角色显示复核.md)。

## 产品职责

首阶段提供独立任务总览，集中展示已注册且契约兼容的业务来源任务：当前角色现在有什么工作，以及其他角色今天有什么工作。当前角色可以为自己或他人执行；已安排工作、开放候选和等待／未知分开展示。“今日”与完成状态由来源业务解释。

中心拥有展示／提醒设置、逐角色刷取计划与可再生任务投影；来源拥有业务状态、周期与完成判断。两个角色列表、账号悬停、当前角色面板与登录提醒复用同一集合，来源操作可通过公开执行契约在工作图标触发，也可打开业务页面。Core 提供连接、统一窗口、设置和入口，不保存业务任务。

后续按真实场景增加独立任务创建、持久需求、任务链、数量分配与人工核实；中心主窗口负责这些自有记录的编辑，悬停支持当前角色来源提供的直接图标操作。目标、配方、库存和邮件事实由对应业务提供，通过 Core 注册与发现的公开契约协作。前期确认的数量与物流规则保留为后续验收约束。
