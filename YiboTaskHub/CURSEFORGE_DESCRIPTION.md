# YiboTaskHub - Action Hub

YiboTaskHub brings explicitly chosen work from supported Yibo addons into one character-aware action hub. Add a goal from a supported business page, review its status by character, and keep progress and completion history together.

## Features

- Add only the goals you choose; new and upgraded installations do not create an automatic task list.
- Review current work, saved goals, and per-character progress in the YiboCore account window.
- Edit, pause, resume, repeat, remove, or copy goals while preserving their history.
- Use supported source actions from the current character's work icons.
- View a compact current-character summary and optional login reminder.
- Keep business rules and collected status with each source addon; TaskHub stores goal choices and derived display state locally.

## Requirements

- World of Warcraft: Mists of Pandaria Classic 5.5.4.
- [YiboCore](https://www.curseforge.com/wow/addons/yibocore) 1.12.0 or later (API v13, localization:1, account-entry:2, builtin-entry-bar:1).

Install YiboCore and YiboTaskHub together. Source integrations are optional; install a supported source addon to see work from that addon. Current integrations include YiboAltoBoss, YiboBuilds, YiboCrafting, YiboCurrency, YiboLegendary, YiboMail, YiboReputation, YiboTodo, and YiboVault.

## Getting started

Open the YiboCore account window and visit a supported addon page. Use its configured add gesture or add button to save a goal. Manage saved goals in TaskHub's Goal Management page. The add gesture can be selected in YiboCore's window settings.

Open the hub with `/yth`. Data is stored locally in WoW SavedVariables. The source addon remains responsible for its own business data and reset rules.

## 中文

YiboTaskHub 将已支持的 Yibo 插件中由玩家主动选择的工作汇总到一个按角色查看的行动中心。可从业务页面添加目标，在账号窗口中查看角色状态，并统一管理目标进度与完成历史。

### 功能

- 只添加玩家选择的目标；新装和升级后都不会自动生成任务清单。
- 在 YiboCore 账号窗口查看当前工作、已保存目标和逐角色进度。
- 编辑、暂停、恢复、重新执行、移除或复制目标，并保留完成历史。
- 通过当前角色的工作图标执行来源插件支持的操作。
- 查看当前角色摘要，并按需启用登录提醒。
- 业务规则和采集状态仍由来源插件负责；TaskHub 在本地保存目标选择及派生展示状态。

### 依赖与兼容

- 《魔兽世界：熊猫人之谜》经典版 5.5.4。
- 必须安装 [YiboCore](https://www.curseforge.com/wow/addons/yibocore) 1.12.0 或更新版本（API v13、localization:1、account-entry:2、builtin-entry-bar:1）。

请同时安装 YiboCore 和 YiboTaskHub。来源插件为可选安装；安装对应插件后，行动中心才会显示该来源的工作。当前已接入 YiboAltoBoss、YiboBuilds、YiboCrafting、YiboCurrency、YiboLegendary、YiboMail、YiboReputation、YiboTodo 和 YiboVault。

### 开始使用

打开 YiboCore 账号窗口并进入已支持的业务插件页面，使用配置的添加手势或添加按钮保存目标。随后在 TaskHub 的“目标管理”页面管理目标。添加手势可在 YiboCore 的窗口设置中选择。

使用 `/yth` 打开行动中心。数据保存在 WoW 本地 SavedVariables 中，来源插件继续负责自己的业务数据和重置规则。
