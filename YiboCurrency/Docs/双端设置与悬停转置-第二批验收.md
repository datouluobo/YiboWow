# 双端设置与悬停转置第二批

2026-11-27。YiboCurrency Mists 1.1.3 与 Forever 0.1.9 工作树，沿用各目标版本号。

## 行为与数据

- Core 设置工作台中的「内置／自定义与其它」使用同一套目录表格与分页。主窗和悬停分别保存选择。Forever 的金币及本端已发现原生货币列在内置页，原生货币继续只用于悬停，主窗列显示破折号。点击自定义物品行可将 ID 填入 Core 物品选择器，移出目录需确认。
- 两端共用悬停转置与 Core 列分页。Forever 默认保留货币为行，开启后角色为行、货币为列。打开与关闭使用同一角色范围、货币字段和读数。Forever 的目标设置新增可选 `hoverTranspose`，旧存档缺省为关闭。
- Forever 继续按物品 ID 管理自定义目录，通过原有扫描请求获取随身数量。物品名仍按 ID 保存在本端映射；移出条目时重置主窗与悬停显示选择，并清除该物品的会话状态。MoP 保留原有目录和物品解析方式。两端沿用各自的采集规则、角色快照、归档及存档格式。本批范围含目录设置和悬停方向，金币和原生货币目标入口留待第三批。
