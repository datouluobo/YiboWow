# 货币目录与显示管理

2026-10-19。实现与离线交互验证完成；本轮游戏客户端验收待完成。适用 YiboCurrency 1.1.0、YiboCore 1.12.6 / API13。

## 操作与数据所有权

| 操作 | 内置货币 | 自定义物品货币 | 状态归属 |
| --- | --- | --- | --- |
| 主窗口显示／隐藏 | 设置列表“主窗口”列 | 同一列、同一接口 | Core 账号字段设置 |
| 悬停显示／隐藏 | 设置列表“悬停”列；主窗口右键或行内勾选 | 同样支持三种操作 | Currency `settings.previewColumns` |
| 加入自定义目录 | 已内置项目提示重复 | 输入 ID、链接、名称或拖入物品，确认后加入 | Currency `settings.customItems` |
| 移出自定义目录 | 不提供 | 选择自定义名称，再使用目录管理的移出按钮并确认 | Currency 执行目录修改与显示偏好清理 |

主窗口和悬停的选择独立，支持全部四种组合。隐藏一个视图中的项目不会移出目录，也不会改变另一个视图。新加入的自定义项目默认遵循主窗口可见、悬停未选中的既有规则。移出目录会清除该项显示偏好；观察快照与实际背包物品保留。

## 界面

- 货币设置分为“内置”与“自定义与其它”两个完整页面。“内置”页仅展示内置货币；“自定义与其它”页展示自定义货币、悬停转置和目录管理。两个页面均使用名称、主窗口、悬停三个共享表头；每项只显示勾选框。目录每页最多24项，并依据Core提供的可用高度分页，为其它控件预留完整空间；加入自定义项目后自动打开所在页。宽窗口两栏按列顺序阅读，窄窗口一栏。
- 本轮按用户要求在货币设置页提供货币专用显示编辑入口。主窗口偏好仍通过 Core 公开字段接口保存，Core“显示与入口”的通用字段管理读写相同状态；悬停偏好仍通过注册的预览字段契约提供。没有第二份显示偏好或业务窗口壳。
- 主窗口在货币名称旁显示“悬停”勾选列。右键名称、数据单元或行背景均切换该项悬停选择；内置和自定义项目通过稳定目录 ID 调用同一方法。表头说明勾选含义，数量摘要区分主窗口显示数、目录总数与悬停数。
- 悬停视图用于查看，不提供会移除正在查看项目的编辑动作。其内容直接使用相同目录与 `previewColumns`，不受主窗口显隐过滤。
- 自定义目录管理位于“数据与缓存”分区。拖入物品只发起加入操作；重复拖入已存在物品提示重复。移出操作使用末尾的风险按钮和 Core 确认框。

## 接口与兼容

`GetCatalogEntry` 根据稳定 ID 解析当前目录项，`SetCurrencyDisplay(id, surface, visible)` 处理 `main` / `hover`，`ToggleHoverCurrency(id)` 供主窗口右键与勾选共用。保留 `SetVisible` / `SetMonitored` 的现有方法形式，并转入同一实现。移出目录后的旧控件 ID 会被拒绝，避免重新写入无效偏好。

继续复用 API13 的 `account-dynamic-fields:1`、`account-preview-field-groups:1`、`account-surface-budget:2`、语言和物品控件能力；Core 公开契约和最低版本未变。启动检查补齐本轮实际调用的公共 UI 方法。CAP-003、CAP-004、CAP-009 在公共能力迁移台账记录本次接入。
