# Currency 双目标 TOC 修复与 CF 包核对

2026-11-09。适用 YiboCurrency Mists 1.1.1 与 Forever 0.1.0。源码工作区原只剩内容为 Forever 的默认清单，且混入生成的发行清单 JSON。保留该 JSON 到 `_NonRelease/CurrencyForever/Release-20261106/Deployed-YiboReleaseManifest.json` 作为历史证据。按统一规范第 2.1 节恢复目标清单和构建映射。

源码的 `YiboCurrency.toc` 只执行 `Common/TocHint.lua`，按客户端语言显示提示，不声明存档或业务入口。MoP 启动和命令入口迁至 `Mists/`。只在实际 MoP 客户端注册登录事件和命令，首次写库移入通过 Core 就绪、API13、所需能力及数据交接检查后的现有存储初始化。登录事件使用一次，重复业务初始化沿用现有幂等保护。Forever 保持现有就绪、最低 API 和能力检查及晚就绪路径，并在错目标时于事件、命令注册前返回。技术名、目录、Slash 命令、存档名和 schema 保持原有约定。未新增 Core 公共能力接入，既有 Locale 和 Core 接口继续复用。

两套目标分别引用自己的启动链，检查未发现 XML 或其它间接引用旧根目录入口。MoP 覆盖模拟保留已发布包的旧根目录 `Bootstrap.lua` 和 `Commands.lua`，新 TOC 只执行 `Mists/` 的入口，实际解包模拟通过单次初始化、存档隔离、错客户端和 Core 未就绪／旧 API／缺能力时停止写库。现有 Forever Smoke 61 项通过，包括默认提示、错端、Core 门槛、重复初始化及模拟保存恢复。适用回归入口 7/10 通过，API13Spec、依赖它的 ScrollBudgetSpec 及 CoreItemControlsSpec 因旧夹具未装配 `Core.Client` 失败，已在未修改的夹具基线上复现。语言扫描无缺失翻译或格式差异，提示命中预启动本地双语资源候选，另有工作区原有的 `MIGRATION.PROBE` 资源缺失候选。

统一构建器分别生成两个临时验证 ZIP。MoP 26 文件／16 条加载引用，Forever 17 文件／7 条加载引用。两包均只有一份默认 TOC，加载项与源码逐字节一致，未夹带另一端实现或源码提示文件。Lua 语法由临时 Lua 5.1 编译入口校验。实际客户端的干净安装、保留旧文件覆盖、首次完整重启选择清单、重载及完整退出后的存档恢复尚未针对本次变更验证。修改后的验证包未判定可发布。
