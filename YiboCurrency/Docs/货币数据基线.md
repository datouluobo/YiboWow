# YiboCurrency 货币数据基线（修订版）

**目标版本**：熊猫人之谜经典版 `5.5.4`（Interface `50504`）

**修订依据**：原基线目录审计、实机客户端货币面板验证、60–90 级货币机制核对。
**本轮范围**：仅修订数据基线文档；运行时 `Catalog.lua` 尚未随本文变更，后续代码任务必须以本文为准同步目录、ID 和顺序。

## 一、状态定义

| 状态 | 含义 |
| --- | --- |
| 当前可获取 | 5.5.4 仍可正常产出、流通或兑换。 |
| 仅存量遗留 | 已停止新产出；客户端仍显示，持有存量仍可使用或兑换。 |
| 过期 | 已停止产出且无对应兑换用途，仅为客户端残留 ID。 |
| 待核验 | 客户端仍需核对显示名称、图标和实际可读性；稳定键已在目录中固定。 |

## 三、修订说明

### 分类与排序

1. 以功能用途而非资料片为一级分组，保持游戏原生货币面板的分组顺序。
2. 长者的好运符仍归入“熊猫人之谜”；化石考古碎片归入“其它”。
3. 同一分组内保留原生面板的条目顺序；代码同步时不得按名称字母序重排。

### 移除条目（3 项）

| 原条目 | 移除原因 |
| --- | --- |
| 灵魂碎片（`item:28558`） | 术士职业专属消耗资源，不属于通用货币体系。 |
| 禅悟珠宝匠硬币（`currency:698`） | 已无正常获取途径，作为废弃专业数据移出通用目录。 |
| 风险硬币（`item:37836`） | 无主流兑换场景，不属于 60–90 级主流货币体系。 |

### 补充与名称校准

1. 补入征服纹章（`item:45624`）、勇气纹章（`item:40753`）、赛德里尔精华（`currency:2589`）、亵渎者的天灾石（`currency:2711`）与竞技场点数（`currency:1900`）。
2. `item:49426` 的客户端显示名称校准为“寒冰纹章”。
3. 至尊石系列统一为“至尊石碎片”（`3350`）、“至尊石碎块”（`3414`）、“至尊石聚簇”（`3416`）。

### 状态判定

- 竞技场点数在 CTM 重做 PvP 货币体系后停止产出；保留为过期客户端残留 ID。
- WLK 纹章及 CTM 勇气/正义点数按仅存量遗留处理：不再产生新余额，但不把其已有余额误显示为零。
- 每项稳定 ID、显示名称、图标与客户端可读性仍以目标客户端实测为准。

## 四、待实机核验

1. 通过 `/ycu probe` 确认本目录每项在目标客户端的显示名称、图标与实际可读性；物品代币尤其需确认背包与银行合计。
2. 确认 `currency:614` 在 5.5.4 的读取数量与兑换状态。
3. 客户端核验只更新 `verified` 记录，不得修改已固定的稳定键或状态分类，除非实测与客户端 API 冲突。
