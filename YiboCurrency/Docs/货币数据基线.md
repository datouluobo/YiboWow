# YiboCurrency 货币数据基线（首批）

客户端目标：熊猫人之谜经典版 `5.5.4`（Interface `50504`）。

| 稳定资源键 | 来源 | 当前采集路径 | 验证状态 |
| --- | --- | --- | --- |
| `money` | 金银铜 | `GetMoney()` → Core `economy` | 已实现；待实机核对格式 |
| `currency:<id>` | 标准货币 | `C_CurrencyInfo.GetCurrencyInfo(id)` → Core `economy` | 首批 ID 待实机逐项确认 |
| `archaeology:<raceKey>` | 考古碎片 | 先用对应稳定 currencyID 探测，保留种族键 | 待确认客户端是否需要独立 API |
| `item:<itemID>` | 物品代币 | `GetItemCount` → Core `economy-items` | 随身已实现；银行在实际打开后标记可知 |

首批探针：永恒铸币（777）、熊猫人/魔古/螳螂妖考古碎片（676/677/754）、公正徽章（29434）。验证失败时必须修正目录或采集路径，不得将失败显示为零值。
