# YiboCurrency - 货币管家

`YiboCurrency` 是依赖 `YiboCore` 的多角色货币余额总览插件。使用 `/ycu` 打开 Core 统一账号窗口中的“货币总览”页面。

账号矩阵集中展示各角色金币、标准货币、节日代币和自定义物品代币，并以来源完整度标记说明物品数量的记录范围。可选接入 YiboVault 补充个人库存位置，帮助快速找到余额所在角色并安排货币使用，减少逐个角色登录核对和手工汇总。

首版收录金币、按稳定 currencyID 读取的标准货币、考古碎片基线和已注册物品代币。主页面显示目录项；Broker/小地图悬停只显示用户标记为监控的项目。两种偏好相互独立。

`0.6` 支持节日货币，包括美酒节奖币、先祖硬币、燃烧之花、万圣节糖果、复活节巧克力和爱情信物；同时兼容不同客户端的物品数量读取方式。

`0.7` 支持拖放背包物品添加自定义货币，并可按 itemID、右键目录项或再次拖放删除；监控排序会按设置页宽度自动分列。

`0.8.0` 可选接入 YiboVault，使用批量个人库存计数生成物品代币余额和来源明细，并纳入已装备物品；同时优化快照复用。`~` 表示已确认数量可能因个人银行或装备来源尚未完整扫描而不完整，不代表估算值。未安装 Vault 时继续使用 Core 快照，已有角色数据无需重新采集。

装备来源计数由 YiboVault `1.0.0-api1` 提供；Vault 对 Currency 是可选依赖。

当前工作树要求 YiboCore **1.8.0（API v9）** 和 `business-services:1`，通过 Core 可选发现 `vault.items`；仓库缺失或不兼容时保留 Core 快照基础功能。自定义物品支持 ID、链接、背包及目录精确名称；同名物品须明确选择。取消或失败保留输入，成功清空。删除位于设置页“数据与缓存”末尾；主账号页仍支持右键删除。存档结构保持兼容。契约见 [API v9](../YiboCore/Docs/API-v9-业务服务与刷新.md)，客户端验收见 `_NonRelease/Tests/CoreItemControls-客户端验收.md`。
