# YiboCurrency 更新日志

## 1.1.0 — 2026-10-19

- 统一内置与自定义货币的主窗口、悬停两列显隐，主窗口右键和行内勾选同步悬停选择。
- 设置拆分为“内置”和“自定义与其它”两页，按可用高度分页，为目录管理和业务控件预留空间。
- 自定义目录明确区分加入和移出，重复拖入不会移出；确认移出清理显示偏好并保留观察快照，加入后定位到所在页。
- 配套 YiboCore 1.12.6 / API13；四种语言组合各1102项集成检查、目录控件及高度检查通过。实际客户端布局与交互复验待完成。

## 1.0.0 — 2026-10-16

- 汇总 Core API13 适配、数量与来源完整度修复、货币数据归属迁移及统一矩阵预算。
- 主表与悬停共用快照和 Core 预算，保留自定义代币与悬停转置设置；旧 Core 历史数据冻结保留，不自动清除。
- 配套 YiboCore 1.12.6 / API13，检查所需能力；相关离线回归通过，统一预算实机检查已获用户确认。
- 按 Mists 目标生成安装包和 GitHub 源码归档。

## 0.9.2 — 统一矩阵预算（2026-10-16）

- 主表与两种悬停接入 Core 统一滚动预算，移除本地槽宽补偿，修复末列被挤到额外分页的问题。
- 最低配套 Core 1.12.6 / API13，并检查 `account-surface-budget:2` 及实际预算方法。
- 相关离线回归通过；用户已确认本轮实机检查无问题。当前仅更新工作树版本，尚未提交或打包发布。

## 未发布 — 货币数据归属迁移（2026-10-15）

- 接管原生货币、金币和随身代币观察，新权威快照写入Currency；旧Core快照逐角色导入并保留历史。
- 最低Core1.12.4工作树 / API13，使用通用档案字段Provider和清理所有者能力2；Core停止货币业务采集，角色档案金币经公开契约消费。
- Vault与本地随身观察按单一来源读取；历史／未知／确认零分开处理，周重置不清零未采集进度，事件合并和失败重试有界。
- 补齐导入恢复、角色别名、pending清理与诊断，旧Core数据无自动清理。实现、验证和客户端清单见Docs/货币数据归属迁移-实施与验收记录.md。

## 未发布 — 数量与API13接入阶段记录（2026-10-15）

- 修复容器兼容API的背包计数；缺失数据不写为0，余额与合计按来源覆盖显示不完整标记。
- 最低Core1.12.4 / API13；接入通用动态字段、名称格式化和中英文资源，显示／悬停选择归并Core统一设置，入口默认三通道关闭。
- 悬停复用主矩阵布局；旧显隐与监控选择保留，Vault通过Core契约发现，补齐集成与数量回归。
- 此阶段的数据仍由Core／Vault提供；后续归属迁移已在上方未发布条目完成。阶段离线证据见Docs/Core-API13-实施与验收.md。

## 未发布 — 货币目标（2026-10-10）

- 原生货币与金币可添加指定角色的一次达标或持续保持目标；货币数量只由 Currency 当前角色快照判断。
- 本轮不把物品代币伪装为原生货币目标。缺少新鲜货币快照时保持未知；需要 Core API v12 / `business-item-actions:1` 及兼容的 TaskHub。

## 未发布 — 仓库能力发现（2026-10-08）

- 最低 Core 提高至 1.8.0 / API v9、business-services:1；仓库集成通过 Core 的 vault.items 契约。
- 仓库缺失、不兼容或子能力不足时保留原 Core 快照；晚注册、注销与变化通过 Core 通知刷新。


## 0.9.1

- 自定义物品编辑接入 Core 选择器，支持 ID、链接、背包及目录精确名称和同名候选选择。
- 添加、删除与拖放复用公共加载及确认；成功清空输入，失败或取消保留输入。
- 设置页删除位于数据与缓存末尾，主账号页右键删除复用相同业务定义。
- 最低要求 YiboCore 1.6.1（API v7），旧 Core 明确提示升级并安全停止初始化；业务存档结构不变。
- 候选与重试控件按状态显示；操作栏按钮等宽、输入框填充剩余空间，右侧预留滚动条间距。

## 0.8.0

- 可选接入 YiboVault，使用个人仓储快照汇总物品代币数量并提供按角色、来源拆分的明细；未安装 Vault 时继续使用 Core 快照。
- 余额统计纳入已装备物品，修正装备中的代币显示为 0；按来源选择 Vault 或 Core 的数量，避免重复累计。
- 个人银行或装备来源尚未完整扫描时用 `~` 标记已确认但可能不完整的数量。
- 读取装备来源计数需安装 YiboVault `1.0.0-api1`；旧版 Vault 未提供该数据时会显示来源未完整标记。
- 通过批量计数和单次视图投影复用库存及角色快照，减少矩阵测宽、绘制、合计和行提示中的重复读取。
- Vault 索引就绪或库存变化时刷新页面；已有角色数据无需重新采集。

## 0.7

- 自定义物品代币支持拖放添加，以及按 itemID、右键目录项和再次拖放删除；删除前显示确认框。
- 添加或删除自定义物品后立即刷新设置页和货币视图。
- 监控排序按可用宽度自适应分列，减少设置页纵向占用。
- 悬停监控不再限制项目数量。

## 0.6

- 支持节日货币统计。
- 修复物品代币数量读取兼容性。
