# YiboCurrency 更新日志

## 0.8.0

- 可选接入 YiboVault，使用个人仓储快照汇总物品代币数量并提供按角色、来源拆分的明细；未安装 Vault 时继续使用 Core 快照。
- 余额统计纳入已装备物品，修正装备中的代币显示为 0；按来源选择 Vault 或 Core 的数量，避免重复累计。
- 个人银行或装备来源尚未完整扫描时用 `~` 标记已确认但可能不完整的数量。
- 读取装备来源计数需安装 YiboVault `1.0.0-api1`；旧版 Vault 未提供该数据时会显示来源未完整标记。
- 通过批量计数和单次视图投影复用库存及角色快照，减少矩阵测宽、绘制、合计和行提示中的重复读取。
- Vault 索引就绪或库存变化时刷新页面；已有角色数据无需重新采集。

## 0.7

- 自定义物品代币支持拖放添加，以及按 itemID、右键目录项和再次拖放删除；删除前显示确认框。
- 添加或删除自定义物品后立即刷新设置页和货币视图。
- 监控排序按可用宽度自适应分列，减少设置页纵向占用。
- 悬停监控不再限制项目数量。

## 0.6

- 支持节日货币统计。
- 修复物品代币数量读取兼容性。
