# Core＋Currency 首批客户端验收

状态：待确认。目标版本：Core 1.6.1（API v7）＋Currency 0.9.1。

- [ ] 旧存档的目录、显示、监控、顺序及余额保持一致。
- [ ] ID、链接、背包精确名称、目录精确名称均能选中客户端物品。
- [ ] 同名不同 ID 展示候选，分页可用；未选择时无法确认。
- [ ] 空输入、非法 ID、无匹配、未缓存和失败均展示反馈；重试可恢复且不无限等待。
- [ ] 添加及回车先确认；接受后目录与账号页刷新，输入清空。
- [ ] 取消及失败保留输入；重复点击不重复确认或保存。
- [ ] 拖放新物品添加、已有自定义物品删除；内置物品受保护。
- [ ] 无效拖放保留光标，合法拖放捕获身份后清除光标，背包实物不变。
- [ ] 设置末尾删除及账号页右键删除共用风险文案，清除关联显示、监控、排序。
- [ ] 加载／确认中修改输入、切页、关闭窗口，旧请求不弹确认或保存。
- [ ] 窄／宽窗口无裁切及横向滚动，操作组位于数据与缓存末尾，足够宽时四个默认控件同一行。
- [ ] 新 Core＋未迁移插件正常；旧 Core＋新 Currency 提示升级且不注册页面。

客户端验收完成后再正式发布本地测试包。AutoOpen、Mail、Vault 分别进入第二阶段接入。
