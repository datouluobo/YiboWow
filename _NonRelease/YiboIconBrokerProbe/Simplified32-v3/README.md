# 32px 主意象简化预览 v3

状态：待确认。日期：2026-10-14。

本版 Core 使用独立的中心圆球和三向连杆，保持 Y 字形端点与透明留白；龙头使用舒展弯角、深靛蓝龙吻和红眼，整体限制在六边形上下顶点定义的图标范围内；TaskHub 中心罗盘收小，圆周与外框之间保留可见间隙。系列主色继续以初始 Vault 的青绿色为参考。
