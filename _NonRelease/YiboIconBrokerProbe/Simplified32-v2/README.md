# 32px 主意象简化预览 v2

状态：待确认。日期：2026-10-14。

沿用五枚图标的适度简化，缩短 YiboAltoBoss 龙角，主体完整落在六边形上下顶点定义的图标范围内。外框决定统一导出比例，主体不能扩大单枚图标的归一化边界。

以初始总览 YiboVault 的青绿色作为配色参考。原始 Vault 外框左侧局部 RGB 中位数约 `(44,235,218)`，v1 Core 相同侧边采样约 `(0,248,253)`，可观察到偏亮和偏青蓝。局部采样用于诊断，不作为整套材质的唯一颜色标准；实际渐变和高光仍需视觉确认。

`Overview.png` 是内置 imagegen 生成的透明预览。`Compare32.png` 包含现用版本和v2五枚草案的32px实尺寸与4倍最近邻放大。灰色属于对照画布；单枚PNG保持透明。

本目录只用于审阅；游戏内仍使用 `MediaTransparent/`。确认后再输出对应游戏纹理。
