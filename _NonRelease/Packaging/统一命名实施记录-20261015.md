# 插件安装包统一命名

2026-10-15；工作树实现，尚未提交或推送本次构建脚本改动。

## 规则与实现

- 安装包：`<Addon>-<目标slug>-v<插件版本>[-api<自身公开API>]-curseforge.zip`。
- GitHub 源码：`<Addon>-src.<源码及配置SHA256前12位>-github.zip`。
- Core API13、Mail API1、Vault API1 从自身实现读取；最低 Core API 是依赖元数据，不能作为其它业务插件自身 API 后缀。
- 14 个现有单目标插件注册 Mists，原入口转调共享打包器；补充 QuestBlocker、TaskHub 的构建入口。
- BeastPaths 保留维护阶段原有三份 TOC、XML 和运行内容，以 universal 表示原集合，复用同一命名与归档函数；上传脚本选择器和项目 AGENTS 命名同步更新。未新增客户端兼容声明。
- 所有入口支持 ValidateOnly 与 Both/CurseForge/GitHub 渠道选择；未知目标、版本不一致或缺失引用拒绝构建。
- 已存在旧包按插件、渠道、目标归档；归档冲突停止，不覆盖，不删除。旧的无目标包名仅用于历史识别。
