### 这批 54 项的离线审查口径修正

- `recipeSpellID → createdItemID` 是客户端 DB2 候选里的制作法术产物关系，不代表 recipe-item 图样关系，也不代表当前可从商人取得。
- 每个候选须区分：当前图样教授、训练师直接教授、旧版本仍保留但无当前来源、动作/历史记录误入宽候选。`SkillLineAbility`、材料和产物效果只能证明它像一个专业制作法术，不能独自决定获取状态。
- 商店图样若标题含“嗜血”，但使用文本教授“恶毒”，应将图样 Item ID 映射到目标 build 中产物关系吻合的 Vicious Spell；不可按名称硬配 `Bloodthirsty` Spell。
- 目前已由用户截图直接核实三条关系：锻造 `66117 → 1224188 → 75124`、制皮 `67042 → 1224196 → 75106`、裁缝 `54595 → 1224160 → 75093`。其余项目以固定 MoP/Cata 外部来源及目标 build 的技能线、材料、成品 ID 配对作为离线证据，不声称每张图样都已在客户端逐张目视确认。
- 这批 54 项目前不需要用户逐项审核，也不需要去商人处实地核验。仅当后续目标 build 数据缺少图样 Item ID→教授 Spell 关系、且不同来源出现冲突时，才提出少量有明确中文图样名和 recipe-item Item ID 的核验项；同时另列制作 Spell ID、成品中文名和 Item ID。

### 54 个历史产物候选与当前 Vicious 候选的逐项配对

按制作家族与装备部位对目标 build 70032 候选作了一对一配对：锻造 16/16、制皮 32/32、裁缝 6/6 均找到对应的 Vicious Spell 候选及产物 Item ID，没有未配对项。逐项数据表为 [CTM 替代配方对照 CSV](5.5.4.70032-ctm-replacement-map.csv)。这份表对每行分开保存历史 Spell ID、历史产物 Item ID、对应的当前候选 Spell ID、当前产物 Item ID；历史产物中文名取自本报告的 Wowhead zhCN 快照，当前产物中文名辅助取自 [zhCN 物品名数据集](https://github.com/kaminaris/wow-item-names/tree/master/retail/zhCN)。ID 配对是主键；未由游戏截图逐项展示的中文名仍需视为外部本地化辅助信息。

本次配对揭示了旧 54 项与此前用户所说“商人图样/训练师学到的配方”并非同一种 ID：这 54 行全是 CTM 成品制作 Spell 与产物候选，并非图样物品 ID。目标 build 候选中的 54 个对应 Vicious 配方均命中本机旧 MoP 目录；其中 6 个裁缝对应项也命中角色正向样本。Cata 专业指南将 Pyrium/Ornate Pyrium、各类 Wyrmhide/Leather/Scale/Dragonscale 与 Fireweave/Embersilk 的 Vicious 配方列为供应商图样；参见[锻造配方表](https://www.wowhead.com/cata/guide/professions/blacksmithing/recipes)、[制皮配方表](https://www.wowhead.com/cata/guide/professions/leatherworking/recipes)和[裁缝配方表](https://www.wowhead.com/cata/guide/professions/tailoring/recipes)。MoP Classic 页面也直接列出图样及教授目标，例如 [Plans: Bloodthirsty Ornate Pyrium Boots](https://www.wowhead.com/mop-classic/item=66128/plans-bloodthirsty-ornate-pyrium-boots)与 [Pattern: Fireweave Pants](https://www.wowhead.com/mop-classic/item=238127/pattern-fireweave-pants)均显示使用后教授 Vicious 成品；用户截图进一步直接验证三条本地教授关系。现有证据支持将 54 个 Vicious 对应候选作为当前供应商配方纳入目录审查，不把旧 Bloodied/Ornate/Fireweave/Emberfire Spell ID 当作当前图样教授关系；没有发现这些对应配方需要归为训练师直学的证据。旧 Spell 如在角色正向数据中出现，仍保留为已学历史事实，不能据此认定当前仍可取得。

证据分级：护腕三行（CSV 中标记为“游戏截图确认代表项”）有目标客户端图样教授文本及目标 build 产物配对；剩余 51 行依据同套装家族/部位映射、固定 Cata/MoP 配方资料和 build ID 交叉匹配作为高可信目录来源证据，没有各自图样 tooltip 的目标客户端截图。当前首版按“已有角色正向样本 + 固定 build 数据 + 固定 AtlasLoot/ATT 资料”的既定规则足以推进目录审查，不要求补齐逐张图样 Item ID；只有发现具体冲突时才向用户请求单项游戏内核实。

## 用户截图案例：附魔武器 - 暴君的卷轴链路

用户提供的 ID 示意列出 `98157`（图纸 Item ID）、`142529`（教授法术 Spell ID）、`98158`（卷轴物品 Item ID）和 `142531`（附魔生效 Spell ID）。对照目标 MoP Classic 资料后，这组 ID 目前无法映射到本版本：当前资料列出的图纸是 Formula: Enchant Weapon - Tyranny，Item ID `254315`，购买成本 4000 荣誉；目标 build 的附魔专业候选是制作 Spell ID `1257682`，Effect=53 的目标是卷轴产物 Item ID `254314`。公开的 MoP Classic 专业资料也将 Enchant Weapon - Tyranny 列为附魔 600 的供应商配方，技能映射数据将 `1257682` 对应至产物 `254314`。因此本项目按目标 build 暂定链路为：`图纸物品 254315 → 学习专业配方 Spell 1257682 → 制作卷轴物品 254314 → 使用卷轴产生武器附魔`。示意中的 `98157 / 142529 / 98158 / 142531` 留作未映射 ID，不与目标 build 的 recipeSpellID 混用，也不据此判断角色已学状态。若以后在目标客户端中实际看到这些不同 ID，再按游戏 tooltip 更新链路；目前无需游戏内核验。

证据：[Formula: Enchant Weapon - Tyranny](https://www.wowhead.com/mop-classic/item=254315/formula-enchant-weapon-tyranny)列出售卖价格和 4000 Honor 来源；[MoP Classic Enchanting 技能页](https://www.wowhead.com/mop-classic/skill=333/enchanting)把 Enchant Weapon - Tyranny 列为 Vendor、600 技能；目标 build 的候选 `1257682` 记录 Effect=53 / ItemType `254314`；独立技能映射也将 `1257682` → `254314`（[Skillet-Classic 映射](https://github.com/b-morgan/Skillet-Classic/blob/master/EnchantData5.lua#L2583)）。
