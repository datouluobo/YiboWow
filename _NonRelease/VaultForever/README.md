# Vault 无限服最小适配验证

运行 `lua _NonRelease/VaultForever/Smoke.lua`，使用[Core客户端夹具](../CoreForever/Harness.lua)加载真实双端清单，模拟采集、存档、窗口和通过Core发现的查询。原始游戏数据不在本目录。

`BaselineRunner.lua` 是自动生成的改动前对照中间文件，通过内存dofile路由加载本任务开始时的共享文件版本，不改写源码。它保留其它工作区状态；不是完整历史仓库。现有测试结果见[对照JSON](LegacyTestComparison.json)。

实现、契约、限制与实机步骤见[最小适配说明](../../YiboVault/Docs/Forever-当前角色物品最小适配.md)。
