# YiboLegendaryProbe

Mists Classic-only, non-release sampler for native quest, faction, item-count, and equipment APIs. It does not load or inspect `YiboLegendary` internals and writes only `YiboLegendaryProbeDB`.

Commands: `/yep capture` samples once; `/yep status` prints a compact summary. The probe performs no automatic capture. Its folder and TOC name match. The probe command is registered in `Docs/Yibo系列插件命令清单.md`.
