# YiboCurrencyProbe

Mists Classic-only native API sampler for player money and the client currency list. It does not load YiboCore or YiboCurrency, inspect a business catalog, or read business SavedVariables. Captures are manual and written only to `YiboCurrencyProbeDB`.

Commands: `/ycp capture` and `/ycp status`. The former `/ycu probe` command read YiboCurrency/Core state and has been removed from the business addon.
