# YiboTodo 可点击动作目录

> 状态：范围已确认，等待逐项动作实机验证。
>
> 本文是 YiboTodo 账号矩阵商业冷却图标动作的首批范围与验收台账。它先于运行时代码定义哪些项目可以点击、点击后的动作、降级行为和验证门槛。

## 1. 总体契约

- 只有当前角色的商业冷却图标具备动作入口；其他角色矩阵图标保持只读。
- 只有商业技能冷却项目进入本功能。日常任务、农场观察、账号级项目、NPC 交互和其它 Todo 项目不进入本目录的可执行范围。
- 当前状态为 `actionable` 且动作实机验证通过时，普通左键直接尝试制作 1 份，不打开商业面板。
- 其它商业冷却状态点击后打开对应专业面板，并尽力定位到目录指定配方。
- 无法定位配方时仍打开对应专业面板，但不得伪装成已经选中配方。
- 直接制作身份与面板定位身份分开记录；两者在当前客户端可能相同，也不得假定永远相同。
- 点击后不乐观修改业务状态。以施法成功、冷却更新或专业数据更新等游戏事件刷新快照，并短暂防止重复点击。
- 制作失败时不自动重试，保留游戏原生错误反馈并解除点击保护。
- `verified` 只表示目录或业务身份已验证；只有动作本身完成实机验证后，项目才可开放点击。

## 2. 动作模式

| 动作模式 | 适用条件 | 点击结果 |
|---|---|---|
| `direct-craft` | 当前角色、`actionable`、动作实机验证通过 | 直接尝试制作 1 份，不打开商业面板 |
| `open-and-select-recipe` | 当前角色、非 `actionable`，且存在可定位的已学习配方 | 打开对应专业面板并选中指定配方 |
| `open-profession-only` | 当前角色、非 `actionable`，但无法可靠定位配方 | 打开对应专业面板，不强行选择 |
| `read-only` | 其他角色，或项目被排除 | 不执行动作，仅显示 Tooltip |

## 3. 选择规则

### 3.1 单配方冷却

单配方项目使用目录中唯一的冷却配方：

- `actionable`：使用 `castSpellID` 直接制作；
- 冷却中、技能不足、未知或其它不可用状态：使用 `selectRecipeID` 或 `selectSpellID` 打开面板并定位；
- 未学习、锁定或身份不足以定位时：降级为 `open-profession-only`。

### 3.2 共享冷却组

只有珠宝和炼金的项目使用共享冷却组规则：

- 矩阵保留一个共享组图标，不拆成多个重复待办；
- 按成员目录的稳定 `order` 查找当前角色已学习且可用的配方；
- 找到第一个符合条件的成员后，直接制作 1 份；
- 不可用时，按同一顺序选择第一个可以定位的成员配方；
- 没有可定位成员时降级为 `open-profession-only`。

### 3.3 同产物的无冷却配方

同一产物存在无冷却或不同材料消耗的配方时，只收录冷却配方。例如：

- “华丽毛皮”只收录消耗 20 皮的冷却配方；
- 消耗 50 皮的无冷却配方不属于 YiboTodo；
- 帝王丝绸、神纹布等项目同样不关心同产物的无冷却配方。

## 5. 每项动作元数据要求

后续 Lua 目录或动作注册实现至少需要提供以下信息：

```text
id
professionID
cooldownGroupID
castSpellID
selectRecipeID 或 selectSpellID
actionMode
fallbackMode
actionStatus
verificationBuild
verificationEvidence
```

共享冷却组还必须记录：

```text
members[]
members[].id
members[].order
members[].castSpellID
members[].selectRecipeID 或 members[].selectSpellID
```

## 6. 实机验证清单

每个准备开放点击的项目必须在目标客户端完成以下验证：

- 当前角色处于 `actionable` 时，点击不会打开商业面板，并能提交 1 份制作请求；
- 制作成功后能通过游戏事件或专业快照观察到冷却变化；
- 材料不足时不会重复制作或错误标记完成；
- 冷却中点击能打开正确专业面板并定位对应配方；
- 技能不足点击能打开正确专业面板并定位对应配方；
- `unknown` 或未学习状态无法定位时，只打开专业面板；
- 共享冷却组按目录顺序选择成员，不重复显示或重复执行；
- 非当前角色图标不会执行动作；
- 短时间连续点击不会提交重复制作请求；
- 事件刷新后矩阵、Tooltip、Broker 和小地图预览仍使用同一份状态。

## 7. 明确排除

- 所有非商业冷却 Todo 项目；
- 无冷却但产物相同的商业配方；
- 自动接取、交付或完成任务；
- 自动寻找 NPC、移动角色或代替玩家进行世界交互；
- 代替玩家处理材料不足、专业未学习或技能不足；
- 其他角色的远程制作；
- 未完成动作实机验证的直接制作。
