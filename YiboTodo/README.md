当前工作树版本为 **1.2.3**，要求 **YiboCore API v13**，并检查 `localization:1`、`account-view:2`、`character-identity:1`、`character-name-format:1` 与 `account-entry:2`。它把已支持的专业冷却、农场操作、日常和特殊活动放进按角色组织的账号矩阵，可用 `/ytd` 打开。

## 功能

- 按监控项目查看各角色的专业冷却与下一次可制作时间。
- 记录农场操作观测；未采集或观测不足时显示待确认。
- 追踪诺米日常、烹饪／钓鱼／珠宝加工日常、纳特三鱼及支持的特殊活动。
- 支持布林顿 4000、开放期暗月马戏团等账号或角色活动。
- 通过图标与状态提示当前可处理、冷却中、准备核对材料或待确认。
- 当前角色适用时，可点击已支持的物品、诺米和专业操作；受保护的游戏动作由安全按钮执行。

监控项目由设置选择。部分信息只在角色实际进入相关专业、任务或场景后才能观测；未见记录不等于已完成或未解锁。冷却就绪不证明材料齐全。农场状态依据已支持的操作观测，不是完整的实时作物扫描。

## 可选行动中心集成

Todo 通过 Core Provider 输出来源任务，供兼容版本的 YiboTaskHub 读取。行动中心目标增强仍独立检查 API v12 与 `business-item-actions:1`；Todo 基础功能要求 API v13。集成状态、能力版本与验收范围见 [更新日志](CHANGELOG.md)及 [行动中心 Todo 接入记录](../Docs/行动中心-Todo全量接入.md)。
