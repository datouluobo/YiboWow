# YiboTodo 1.2.0

**当前工作树版本，尚未发布。** 本文件下的 1.2.0 与“未发布”条目记录仓库功能及其发布状态；不得视为已上传 CF 的版本。

## 未发布 — 活动主动添加（2026-10-10）

- 专业冷却、农场、诺米、日常和特殊活动可按其业务目录添加角色或明确账号范围目标；来源仍负责状态、周期与完成判断。
- 兼容一次已确认的专业冷却可作为本周期完成证据；预计可用、未扫描和过期快照不会被当作完成。目标能力需要 Core API v12 / `business-item-actions:1`；基础 Provider 使用 Core API v11。

目标评估在专业数据尚未就绪时提供可选 display.item／icon 元数据，供行动中心显示目录图标；待核实状态与执行准入仍由来源规则决定。

诺米任务投影补传物品／图标元数据，行动中心复用原业务图标；状态与操作定义保持一致。

## 未发布 — 行动中心图标执行（2026-10-10）

- action.targets v1.2 通过 Core 提供 GetClickAction／AfterClick；Task 主列表和悬停可使用诺米物品、选中诺米，以及打开专业／制作一次。
- Todo 原图标与 Task 复用 Actions:Describe，执行由硬件点击的安全按钮完成；专业点击后走原合并采集，不提前完成目标。

## 未发布 — 农场目标修复（2026-10-10）

- 目标校验补查 farmOperations 目录，农场操作可主动加入行动中心。复用原农场快照与日重置规则；无观察时待核实，一次已验证操作仍按既有整轮投影，不另建完成规则。

## 未发布 — 行动中心显示目录（2026-10-10）

- action.todo 来源新增可选 displayGroups 目录与 task.displayGroup，公开稳定项目 ID 和标题。专业冷却目录不依赖角色是否采集，诺米／活动继续由来源维护目录。
- TaskHub 可逐项目保存展示偏好；不修改 Todo 的监控、采集、完成判断或数据库。沿用现有 Core Provider 契约与版本检查。

## 未发布 — 任务链性能修复（2026-10-10）

- 2026-10-10 性能修复：不变日常／活动观察不再失效全账号快照；固定整分钟重置边界，避免逐秒漂移。任务链角色枚举使用 Core character-identity:1；最低 Core API v11 并检查该能力。
