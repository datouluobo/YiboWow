# 熊猫人之谜橙披任务线：任务数据基线

> **范围**：熊猫人之谜（MoP）传说披风／“橙披”任务线；以 **MoP Classic 当前任务数据** 为基准。
>
> **已确认**：整条任务线由前置任务和 **第 1–5 章**组成。章节名依次为：黑王子的试炼、拉西奥的战争、黑白王子、天神的祝福、黑王子的审判。
>
> **用途**：这是跟踪与 UI 展示的数据基线。`任务编号` 是本项目稳定 ID；`Wow 任务 ID` 可用于游戏 API（如 `C_QuestLog.IsQuestFlaggedCompleted`）查询完成状态。不要以本地化任务名作为程序主键。

## 1. 数据约定

| 字段 | 含义／建议 |
| --- | --- |
| 任务编号 | 稳定、面向本项目的 ID；分支以 `A`（联盟）或 `H`（部落）结尾。 |
| Wow 任务 ID | 游戏内任务 ID；用于实际完成状态、任务日志和本地化名称查询。 |
| 前置 | 应完成的本项目任务编号；`/` 表示二选一阵营分支。 |
| 状态 | 推荐枚举：`locked`、`available`、`in_progress`、`completed`、`unavailable`。 |
| 进度 | 需记录 `current`、`target`、`updatedAt`；交谈／交任务型可使用 `1/1`。 |
| 版本差异 | MoP Classic 与原始 5.x 数值不同之处必须保留，不能硬编码为单一数值。 |
| 声望门槛 | 独立于任务完成状态的解锁条件。门槛已满足时，关联“声望任务”可能不出现或被自动跳过。 |

### 推荐最小记录结构

```lua
-- 角色维度；definitionId 为下方“任务编号”，questId 为 Wow 任务 ID。
{
  definitionId = "ORANGE-C2-03",
  questId = 32429,
  status = "in_progress",
  progress = { current = 1875, target = 21000 }, -- 仅示例，声望用当前/目标值
  updatedAt = 0,
}
```

### 声望门槛：必须独立判定

声望任务的“接到／完成”记录**不是可靠的唯一前置**。若角色在声望门槛任务出现前，已经通过击杀、地下城或其它活动取得足够的黑王子声望，客户端可能不会向任务日志提供该声望任务，或服务端直接放行后续任务。

因此，后续解锁应使用：`前序剧情完成 AND reputationRank >= requiredRank`，而不是 `前序剧情完成 AND 声望任务已完成`。声望任务在 UI 中宜显示为“声望门槛”，而非不可缺少的待接任务。

| 门槛编号 | 关联任务 | 所需黑王子声望 | 解锁规则 | UI／记录处理 |
| --- | --- | --- | --- | --- |
| ORANGE-REP-01 | ORANGE-C1-03：Trial of the Black Prince | 尊敬 | C1-02 与声望门槛均满足后，解锁 C1-04。 | 若 31468 未接到但已尊敬，标为 `satisfied_by_reputation`，不可标红为“缺失”。 |
| ORANGE-REP-02 | ORANGE-C2-04：The Prince's Pursuit | 崇敬 | C2-03 与声望门槛均满足后，解锁阵营 PvP 任务 C2-05*。 | 记录当前声望等级；不能用 32429 未完成阻塞后续判断。 |
| ORANGE-REP-03 | ORANGE-C3-04：I Need a Champion | 崇拜 | C3-03 与声望门槛均满足后，解锁 C3-05。 | 若已崇拜，提示“门槛已满足（任务可能跳过）”。 |

推荐增加以下派生状态，而不是强行伪造任务完成记录：

```lua
{
  definitionId = "ORANGE-REP-02",
  sourceQuestId = 32429,
  requiredReputationRank = "REVERED",
  reputationRank = "REVERED",
  gateStatus = "satisfied_by_reputation", -- 或 pending / completed_by_quest
}
```

```text
前置 → 第 1 章：黑王子的试炼 → 第 2 章：拉西奥的战争
```

### 第一章并行要求（截图确认）

`ORANGE-C1-02`「敌人的力量」与 `ORANGE-C1-03`「黑王子的试炼」属于同一阶段的并行要求：

- 敌人的力量：力量印记 10 个、智慧印记 10 个；任务日志截图中的实时进度为力量印记 3/10、智慧印记 1/10。
- 黑王子的试炼：黑王子声望达到尊敬；截图显示该要求已完成。
- 两项全部满足后，才可进入 `ORANGE-C1-04`「恐惧本身」。

任务路线仍按一个角色一行展示；并行要求只作为同一角色当前目标的补充信息，不拆分为多行。

截图进一步确认：完成「创造传奇」后，这两个任务会同时接取；初始目标显示为黑王子声望 0/1、力量印记 0/10、智慧印记 0/10。

### 第三章纳拉克单人完成方法（截图确认）

「暴风领主之魂」可以单人完成，简要步骤：

1. 先完成雷神岛单人战役中的“雷神之基”步骤，并准备淬冰闪电长枪。
2. 对纳拉克使用长枪，然后跑到副本门口，让 NPC 把怪拉出来。
3. 长枪 1 分钟冷却后再使用一次，躲避追来的怪几秒，任务即可完成。

## 8. UI／跟踪实现注意事项

1. **分支显示**：只显示角色阵营对应的 `C2-05*` 与 `C2-07*`；数据层保留两条定义，方便统一引用 Wow 任务 ID。
2. **可并行项**：C1-02/C1-03 属于并行门槛。界面不应误显示成必须先后完成；应在 C1-04 显示“印记、声望均完成后解锁”。
3. **声望任务可能缺席**：C1-03、C2-04、C3-04 仅是声望门槛的任务化表现。当前声望已达对应等级时，即使 Wow 任务 ID 不在日志且未有完成记录，也要放行后续任务，并显示“声望已满足”。
4. **数值型目标**：印记、勇气、秘史、延极锭、符文石、永恒铸币都应显示 `current/target`；对声望显示声望等级及数值进度。
5. **阶段锁定**：章节可用性除前置外还受服务器阶段影响。`phaseAvailable` 应是独立字段，阶段未开放时使用 `unavailable`，不要误记为玩家未完成。
6. **完成判定**：优先按 `Wow 任务 ID` 查询；任务物品数量只能作为进行中进度，不能替代完成记录。声望门槛例外，按本节的 `gateStatus` 判断。最终状态以 `ORANGE-C5-05` 为准。
7. **奖励状态**：`C4-02` 与 `C5-04` 需要单独记录选择的披风／最终披风物品 ID，供角色总览展示；任务完成不等同于装备穿戴。

## 9. 待运行环境确认

本清单依据 MoP Classic 数据库（当前页面标记为 5.5.4）整理。接入插件前，需要在目标客户端实测以下 API／数据是否可读：

- `C_QuestLog.IsQuestFlaggedCompleted(questId)` 是否能返回上述历史／当前阶段任务；
- 当前阶段是否改写了任务目标、掉落来源或数量；
- 阵营变更后分支任务的完成状态映射；
- 是否有官方追赶机制造成“前置未按原序完成但可直接进入后段”的情况。
