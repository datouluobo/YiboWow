# YiboLegendary — 传说之路

当前工作树版本为 **2.2.1**，最低依赖 **YiboCore API v13**，并要求 `localization:1`、`character-name-format:1`、`account-view:2` 与 `account-entry:2`。插件通过统一账号页追踪多角色的传说装备进度，使用 `/yle` 打开。

## 功能范围

- 熊猫人之谜传说披风：章节、任务、目标、声望要求、勇气点数累计及下一步。
- 传说武器收集路线：风剑、萨弗拉斯、索利达尔、埃辛诺斯战刃、瓦兰奈尔、影之哀伤、巨龙之怒和龙父之牙。
- 按角色和职业适用条件展示路线进度；双件装备按所需件数判断目标完成。
- 对可观测物品使用背包／装备扫描记录最终物品与中间节点；其它节点按任务或业务数据采集。
- 统一账号页、角色范围与排序；Broker／小地图入口和悬停预览由 YiboCore 管理。

各路线的数据证据并不相同：披风提供较完整的任务线状态；其它目标依据已支持的物品、任务与事件记录检查点。旧角色无法回溯插件安装前的所有历史。

## 当前开发状态

工作树还提供可选行动中心目标：可按角色添加披风或已支持传说装备目标，追踪来源快照和一次性完成状态。该集成单独要求 Core API v12 / `business-item-actions:1` 及兼容的 TaskHub。Core 语言设置用于菜单、矩阵表头、按钮、控件及通用状态／错误提示。任务步骤、专有名词、路线说明和目标进度保留原始中文文案；目前没有可信的官方英文任务文本可供逐项校对。工作树另包括事件合并采集和页面局部刷新优化；未发布部分见 [更新日志](CHANGELOG.md)。
