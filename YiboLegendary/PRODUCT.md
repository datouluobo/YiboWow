# YiboLegendary - 传说之路

`YiboLegendary` 是面向 MoP Classic 5.5.4 的账号级传说物品获取进度插件。它将每个角色对传说目标的获得状态、当前检查点与下一步汇总到 YiboCore 的统一账号视图。

## 2.0 产品目标

玩家应能先在入口悬停中比较“哪名角色最接近哪件传说物”，再打开完整页面了解该物品的获取路线和所有适用角色的完整进度。

2.0 正式支持：

- **传说披风**：黑王子任务线；保留章节、并行要求、声望门槛、勇气累计及阶段开放判定。
- **雷霆之怒，逐风者的祝福之剑**：两个关键掉落、元素锭收集与最终事件。

未来目录仅覆盖经典旧世至 MoP Classic 5.5.4；WoD 及后续版本不在当前客户端范围内。

## 信息架构

- **完整页面**：传说目标目录、所选目标的路线说明，以及角色的当前检查点、进度和下一步。
- **悬停预览**：角色为行、传说目标为列的矩阵；每格显示获得状态和当前检查点。
- **同一快照**：完整页面、悬停、Broker 与小地图均读取同一份角色—目标快照，不维护第二套摘要判断。

YiboCore 负责窗口壳、角色范围、滚动、入口与设置工作台；本插件只负责目录、路线规则、采集和业务视图。

## 数据与测试

- 路线由稳定目标 ID 与节点 ID 定义，不以本地化名称作为主键。
- 路线类型只是目录分类；长任务链、掉落／收集链和直接掉落均解析为统一的角色—目标状态。
- `/yle probe` 检查客户端能力，`/yle status` 输出当前选择目标的摘要。
- `/yle test THUNDERFURY <节点>` 写入仅供开发验证的临时投影，永不覆盖真实采集结果。
