# YiboAltoBoss 2.4

## 中文

- 新增节日 Boss 追踪：活动日历确认开放后，科林·烈酒会自动加入首领追踪账号矩阵。
- 每个角色按服务器日显示奖励状态，并识别每日任务与地下城查找器完成奖励；人工标记会明确显示来源。
- 可在行动格直接排队或取消节日副本队列；“位面 / 职责”格显示当前已选职责与不可排原因。
- 首领追踪设置新增默认开启的“节日 Boss”开关。

## English

- Added seasonal Boss tracking: Coren Direbrew appears in the account matrix when the in-game calendar confirms Brewfest is active.
- Per-character rewards are tracked by server day from daily quests and Dungeon Finder completion rewards; manual marks clearly identify their source.
- Join or leave the seasonal queue directly from the Action field; the “Phase / Role” field shows selected roles and queue eligibility details.
- Added a default-on “Holiday Boss” option to Boss Tracker settings.
