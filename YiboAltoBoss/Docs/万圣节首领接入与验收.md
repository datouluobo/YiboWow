## 问题与实现

此前节日目录仅有科林·烈酒，日历刷新也无法生成无头骑士行。新增稳定 ID `holiday:headless-horseman`，显示名通过既有 owner 语言资源读取：中文“万圣节·无头骑士”，英文“Hallow's End · Headless Horseman”。

无头骑士按当前客户端日历的万圣节事件显示，支持简体、繁体及英文标题，不使用固定年份或日期推定开服活动。日历未就绪时暂不自动展示，沿用既有 `CALENDAR_UPDATE_EVENT_LIST` 刷新流程；缺失或关闭节日时不会推定活动可用。账号页及入口预览继续共用 `GetBossList`，角色完成状态由 AltoBoss 自有快照管理。

复用节日每日状态、07:00 刷新、手动标记、排队角色选择与排队操作。LFG ID 为 285，奖励任务标识为 25482；自动完成来自每日奖励查询、奖励任务完成或匹配副本的 `LFG_COMPLETION_REWARD`。队列入口仍核对客户端返回的节日副本标志、名称和角色准入，不能匹配时停止排队操作并提示。LFG ID 可交叉核对 [TrinityCore 首领源码](https://master.trinitycore.net/d5/da6/boss__headless__horseman_8cpp_source)；目标怀旧客户端的奖励标志及每日刷新仍须实机验收。

节日目录与计划观察改为枚举已有节日定义，行动中心继续通过现有 Core 契约取得节日目标。新增无头骑士目录项，不变更接口结构、权威数据所有权或最低 Core API13。玩家关闭手动节日显示后，显式添加的行动中心目标仍可独立观察，沿用原有约定。
