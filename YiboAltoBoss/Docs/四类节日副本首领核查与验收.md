## 行为与失败处理

- 四类首领均纳入原有节日目录，主表、入口预览、排队操作和行动中心目录共同枚举这份定义。科林和无头骑士的稳定 ID、历史记录不变。
- 活动开放统一查询客户端日历。移除科林的固定日期限制，避免实际活动日期调整后被再次过滤。支持简体、繁体及英文日历和副本名称识别；玩家可见显示名使用 owner 中英文语言资源。
- 进入世界时调用可用的 `C_Calendar.OpenCalendar` 请求数据；沿用 `CALENDAR_UPDATE_EVENT_LIST` 的状态观察与页面刷新。日历尚未就绪或接口不可用时暂不自动显示，不把全年副本名称存在视作活动开放。
- 日历加载完成后明确没有对应活动时，目标返回活动关闭；未加载时保持未确认。日历更新同步失效行动中心进度，下一期活动可重新开放同一目标。
- 查询日历时按当前服务器时间确定当天，并在客户端提供 `GetMonthInfo` 时换算相对正在浏览月份的偏移。浏览其它月份不应改变当天活动判断；该可选 API 不存在时沿用偏移0的旧调用兼容形式。
- 主表与显式目标共用每日状态观察。奖励任务或每日副本奖励任一明确完成即可记录；两者都明确为未完成才记已观察可用。接口缺失、异常或返回未确认值时保持未知。完成记录不因一次未完成查询而撤销。
- 每日状态沿用现有07:00周期，离线角色无当日记录时保持未观察。角色能否排队、节日副本名称及标志仍由客户端校验，不预设等级或装备要求。
- 关闭节日显示隐藏自动行；通过行动中心显式添加的目标继续独立观察。排队与取消共用原有入口，奖励事件仅归属匹配的节日副本。
