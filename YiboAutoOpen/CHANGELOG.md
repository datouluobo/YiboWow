# 更新日志

## 0.1.3（Forever）

- 与 Mists 1.2.10 同步共享背包扫描和队列代码。无限服沿用现有容器筛选及开启流程，锁箱识别和解锁后复查待本服取证。

## 1.2.10（Mists）

- 自动开包按背包格检查锁定状态。已锁的箱子保留在目录里并静默跳过。
- 盗贼开锁成功或交易窗口关闭后，短暂等待客户端更新锁箱状态，再复查背包。

## 1.2.5

- 物品使用被客户端保护机制拦截时，停止该物品本次会话的自动重试，并提示手动开启；其它目录物品继续处理。
- 裂纹的蚌壳（24476）标记为仅手动开启，命令、输入或拖放添加时直接提示，不加入自动开包目录；加载时清理旧目录中的该物品。

## 1.2.4

- 更新 Mists 维护版号与对应 TOC 元数据。

## 1.2.3

- 将可选 YiboCore 设置集成更新为 API v13 与 `localization:1`；Core 缺失或版本不兼容时明确提示，独立自动开包与 `/yao` 命令保持可用。

## 1.2.2

- 修复拾取泥土等白名单来源时，绑定确认框先显示在默认位置再跳到鼠标位置的问题；确认框首次显示即完成鼠标定位。

## 1.2.1

- 重构容器失败队列：失败物品移至队尾，独立计数并逐项隔离，避免单个坏物品阻塞其它目录物品。
- 世界切换与设置页刷新会重新核验敏感界面状态，修复副本进出后残留 `SENSITIVE_UI` 暂停及刷新无效的问题。
- 安全条件暂时不满足时延后判定待处理操作，避免把读条、战斗或界面状态误记为物品失败。

## 1.2.0

- 新增确认框来源白名单管理、最近可添加对象、来源启用勾选和别名编辑。
- 内置目录箱子来源不可删除；自定义来源支持对象 ID、别名和删除管理。
- 确认框定位继续仅作用于明确启用的白名单来源。

## 1.1.1

- 调整自动开包设置页的响应式紧凑布局；常规宽度下将三项开关合并为一行，减少纵向占用。
- 修正发布包文件清单，确保包含 BOP 确认框辅助模块。

## 1.1.0

- 新增“BOP 确认框跟随鼠标”可选功能；仅移动游戏原生确认框，仍须玩家手动确认或取消。
- 深渊蚌（`52340`）明确标注为仅手动开启，目录与命令会提示该限制。
- 改进 BOP 确认框在重载、快速拾取与不同 UI 布局下的兼容性，并优化自动开包设置页布局。
