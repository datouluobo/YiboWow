# 更新日志

## 1.2.0

- 新增确认框来源白名单管理、最近可添加对象、来源启用勾选和别名编辑。
- 内置目录箱子来源不可删除；自定义来源支持对象 ID、别名和删除管理。
- 确认框定位继续仅作用于明确启用的白名单来源。

## 1.1.1

- 调整自动开包设置页的响应式紧凑布局；常规宽度下将三项开关合并为一行，减少纵向占用。
- 修正发布包文件清单，确保包含 BOP 确认框辅助模块。

## 1.1.0

- 新增“BOP 确认框跟随鼠标”可选功能；仅移动游戏原生确认框，仍须玩家手动确认或取消。
- 深渊蚌（`52340`）明确标注为仅手动开启，目录与命令会提示该限制。
- 改进 BOP 确认框在重载、快速拾取与不同 UI 布局下的兼容性，并优化自动开包设置页布局。

## 1.0.0

- 首次发布：默认目录基于既有自动开包 WA 的 40 项顺序。
- 修正深渊蚌 ID 为 `52340`，并启用塞满战利品的南瓜（`54516`）。
- 支持独立命令模式与可选 YiboCore API v6 图形设置增强。
