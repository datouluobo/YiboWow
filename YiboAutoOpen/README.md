# YiboAutoOpen 1.0.0

安全地逐个开启账号目录中的容器。目录是明确的允许列表，不依赖客户端并不稳定的“可拾取”标记；默认会在登录时扫描已有物品。

YiboCore 是可选增强：未安装 Core 时，自动开包与 `/yao` 命令完整可用；安装 API v6 Core 后，可在统一设置工作台调整开关、空位阈值、提示和目录。

命令：

- `/yao add <物品链接、ID 或名称>`
- `/yao del <物品链接、ID 或名称>`
- `/yao list [页码]`
- `/yao status`

插件不会改变游戏的自动拾取设置，也不会点击确认框或奖励选择。战斗、死亡、载具、施法、拾取窗口、敏感界面或通用背包空位不足时会暂停。单个物品连续失败两次后，仅在本次登录跳过它。
