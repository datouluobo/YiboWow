# YiboAutoOpen 1.2.0

安全地逐个开启账号目录中的容器。目录是明确的允许列表，不依赖客户端并不稳定的“可拾取”标记；默认会在登录时扫描已有物品。

YiboCore 是可选增强：未安装 Core 时，自动开包与 `/yao` 命令完整可用；安装 API v6 Core 后，可在统一设置工作台调整开关、空位阈值、提示、目录和“确认框位置”。确认框位置功能只处理白名单来源：YAO 自己打开的目录箱子，以及你通过“最近可添加对象”主动加入的游戏对象；关闭后确认框保留游戏原生位置。

命令：

- `/yao add <物品链接、ID 或名称>`
- `/yao del <物品链接、ID 或名称>`
- `/yao list [页码]`
- `/yao status`

插件不会改变游戏的自动拾取设置、不会点击确认框，也不会选择奖励。YAO 自动开启物品而触发“拾取后绑定”确认时，会把该游戏原生确认框临时移到触发时的鼠标位置，仍须由玩家亲自点“确定”或“取消”；取消后该物品仅在本次登录跳过。深渊蚌（52340）在 MoP 客户端只能手动开启，YAO 会跳过它。战斗、死亡、载具、施法、拾取窗口、敏感界面或通用背包空位不足时会暂停。单个物品连续失败两次后，仅在本次登录跳过它。
