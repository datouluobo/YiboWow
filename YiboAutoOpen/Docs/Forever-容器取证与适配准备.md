# Forever 容器取证与适配准备

日期：2026-10-23。状态：取证工具代码完成，业务实现待真实容器及操作证据。尚无Forever正式TOC、版本或允许目录。

按[适配计划](../../Docs/Yibo系列-无限服适用性与适配顺序-2026-10-19.md)，AutoOpen在有真实容器样本后可提前。既有环境样本只有炉石等普通物品，不能证明任何对象适合自动打开；MoP允许目录不直接迁移。

本轮复用独立[天赋与容器探针](../../_NonRelease/YiboBuildsForeverProbe/README.md)的 `/ybf bags`、`/ybf item <袋> <槽>` 与report，以同一套有界报告实现记录物品ID、提示、数量、锁定/冷却、战斗/施法/载具状态和前后位置。只读接口采用固定白名单，使用/拾取/确认接口仅盘点存在性，拒绝调用。

集中实机取一个玩家本来准备打开的真实容器，保留原生提示和采样，正常手动打开后记录数量/位置变化与拾取、绑定或保护确认，再采一次。没有对象时登记前置条件未满足。首批只为经过对照的itemID建立本服目录；单项失败恢复、安全暂停与确认流程分别实机验证，保护动作不能用接口存在性替代许可。

正式实施时以实际涉及的打开队列/安全暂停职责为边界，将MoP专用API、事件和目录归Mists，本服内容归Forever，稳定队列算法按需共享。误装须在建库前停止，存档保持目标隔离。需要Core公开能力时先检查现有操作确认、物品解析、语言和设置能力及最低版本；原本独立的功能不为占位引入Core。本轮没有正式业务运行diff和Core调用变化，不触发未改动旧模块迁移。

取证工具43项离线检查通过；客户端采样与容器业务均待。工具不会执行打开，不构成AutoOpen Forever开发完成、实机通过或可发布。
