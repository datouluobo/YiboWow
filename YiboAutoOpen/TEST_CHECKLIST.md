# YiboAutoOpen V1 测试清单

- 仅加载本插件：登录无 Lua 错误；`/yao add` 支持链接、ID、缓存名称；`/yao list` 默认目录有两页。
- 验证战斗、商人、银行、邮箱、交易、拍卖、公会银行、虚空仓库、拾取窗口与空位不足都会暂停，恢复后继续。
- 验证目录允许列表中的容器即使未提供 `hasLoot` 标记也能使用；堆叠和多个格子的容器均会逐个处理。
- 验证 A 失败后队列先尝试 B；不同 ID 轮转且独立计数，耗尽重试边界后逐项隔离，不会无限轮转或堵住后续物品。
- 验证只有一个失败 ID 时有界重试并隔离；同 ID 多个背包槽位不会制造重复候选，尝试前会重新定位当前槽位。
- 验证自动失败隔离可由退避到期和世界恢复事件清除；玩家取消绑定确认的隔离不会被切图、读条结束或新物品事件清除，只能由明确的人工重试清除。
- 同时加载 Core API v6：设置导航出现“自动开包”，但账号主页、显示与入口、Broker 和小地图没有它。
- 运行 Lua 5.1 语法检查、TOC 路径检查、Slash 唯一性检查和 `git diff --check`。

自动化队列状态规则详见 `../Docs/YiboAutoOpen-队列与失败恢复规则.md`。
