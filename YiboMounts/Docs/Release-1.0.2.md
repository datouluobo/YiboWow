# YiboMounts 1.0.2

目标：Mists / MoP Classic 5.5.4。日期：2026-10-25。

修正现代 Classic 增益光环第 10 位法术 ID 的读取，保留旧第 11 位格式支持。名称查询无结果时仍能按光环 ID 显示坐骑来源；减益过滤与提示去重继续生效。冷酷角斗士的暮光幼龙（101821）来源路径和备注统一为第 10 赛季。

S1–S15 全部 15 只正式赛季坐骑的 240 组离线回归通过，Lua 冒烟和 Python 目录校验通过。详细范围见 [PvP 赛季坐骑提示复核](Mists-PvP赛季坐骑提示复核.md)。本轮实机增益、其它入口、重载与完整退出恢复仍待完成，离线打包不代表已完成客户端验收或已上传发行渠道。

本轮沿用 1.0.1 的加载清单与文件路径，插件目录、YiboMountsDB、YiboMountsDiagnostics 及存档 schema 不变。安装使用 Mists CurseForge ZIP，覆盖同名目录并保留 WTF 存档；GitHub ZIP 用于源码查阅。一个安装目录使用一个更新管理来源，整合包与单体共管尚未验证。
