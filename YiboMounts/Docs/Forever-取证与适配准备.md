# Forever 坐骑：取证与适配准备

日期：2026-10-23。状态：**取证工具完成，业务实现待正向样本**。本轮未创建Forever正式TOC、版本或坐骑目录，原MistsTooltip与来源数据未改动。

依据 [已确认适配顺序](../../Docs/Yibo系列-无限服适用性与适配顺序-2026-10-19.md)、[当前台账](../../Docs/无限服适配与发布验收台账.md) 和 [多版本规则](../../Docs/多版本开发规则.md)，首批范围是本服坐骑来源与收藏状态Tooltip；当前功能不扩展为完整坐骑任务管理。

## 当前证据与阻断

现有 `YiboForeverProbe/Samples` 只记录 `C_MountJournal.GetMountIDs` 与 `GetMountInfoByID` 存在，没有调用结果、正向坐骑对象、来源文字或收藏/资格状态变化。2026-10-23只读检查本机无限客户端SavedVariables时，未发现Mounts业务/诊断存档。因此不能把MoP目录、元组字段含义或账号收藏范围直接移用于Forever。

## 本轮交付与集中测试

新增独立 [YiboProgressForeverProbe 0.1.0](../../_NonRelease/YiboProgressForeverProbe/README.md)。打开原生坐骑收藏后执行 `/ypg mounts`；每页最多100条，后续页使用 `/ypg mounts 2`，特定对象使用 `/ypg mount <mountID>`。报告保留目录、原始信息元组、来源/描述、观察者GUID、build、时钟与最近收藏事件，未固定任何元组位置的业务解释。

首批目标至少需要以下实机证据：

| 样本 | 原生对照 | 得到证据后可做的范围 |
| --- | --- | --- |
| 一个已收藏对象 | 名称、mountID/spellID、原生已收藏与可用状态 | 本对象收藏读数与资格字段含义 |
| 一个未收藏对象 | 原生未收藏、是否对角色隐藏、是否可使用 | 明确未收藏与未知/隐藏/不可用的区分 |
| 来源与可获得性 | 同一对象的原生来源文字、来源对象ID/位置或实际获取记录 | 独立Forever目录的经证实条目 |
| 新增收藏或已收藏状态变化（有条件时） | 变化前后原生状态和原始读数 | 实际刷新事件、缓存失效与Tooltip刷新 |
| 重载/完整退出恢复 | 同对象原生状态与再次读取 | 生命周期稳定性 |
| 另一角色/规则集（声明共享范围前） | 同对象收藏事实与角色使用资格分别对照 | 共享获得、角色可用与规则集边界 |

当前没有已收藏坐骑时，先采未收藏和来源样本，状态写为前置条件未满足。空目录、API存在或一次原生截图不能扩大为全部收藏系统已适配；原生来源文字也不能单独证明当前可获得。

## 获得样本后的最小职责边界

- 本服mountID、spellID、物品/NPC/任务等来源事实与收藏API适配放入 `Forever/`，带样本build、来源和验证状态，按实际内容追加。MoP历史目录不复制、不混入本服目录。
- Tooltip/来源格式化/目录查询的稳定框架按实际职责拆分到 `Common/`；客户端挂钩、API和静态目录按目标隔离。现有Tooltip直接查询坐骑API，本次未触及，后续移植时作为完整职责单元审查。
- 收藏状态、当前角色资格和隐藏状态独立表达；缺数据或接口异常保留未知，不显示为未收藏。共享收藏事实仅在范围已证明后合并，当前角色可用性仍分开判断。
- Mounts拥有目录、来源与收藏业务，Core不接管收藏规则。新目标存档独立，不读取其它业务插件私有对象；本轮不预建TaskHub目标服务。

## 本轮迁移与Core能力审查

本轮没有修改Mounts业务运行代码、TOC或Core接口，未发生运行模块迁移和最低版本变化。独立非发布探针仅保留原始样本，不提供正式Tooltip、入口或业务设置，不消费Core能力；玩家可见诊断文本以稳定键提供中英文，GUID只标识观察者。

正式目标实施时沿用项目当前已验证Core基线，按实际范围接入API13/`localization:1`与CAP-009语言；若使用物品/名称、设置或持久快照，再核对CAP-001/003/004/007/010。缺能力提示升级并停止依赖路径，不保留平行语言回退。当前状态不记为任何Forever业务能力已接入。

## 验证与后续门槛

新增探针72项Lua5.1模拟、3份Lua语法通过；包括多返回nil洞、false/零、来源文字、受限值、分页、无过滤器修改/召唤、保存、重复加载、转场与误装停止。Mounts正式源码未变化，原支持目标行为没有新增结论。探针实机加载、收藏与来源对照、变化事件、重载/退出和共享范围均待测；满足一个可交付的本服目录与收藏闭环后再实现Forever版本。本轮不进入发布检查。
