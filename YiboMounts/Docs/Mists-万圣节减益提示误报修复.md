# Mists 万圣节减益提示误报修复

日期：2026-10-25。源码版本：1.0.1。状态：离线验证通过，实机复测待完成，未上传发行渠道。

## 问题与修复

用户截图中万圣节“恶作剧”减益的原生提示混入坐骑成就、商人和价格来源。代码审查发现：读取光环法术 ID 失败时，旧实现遍历光环返回值中的全部数字，任一数字命中坐骑目录便追加来源。持续时间、到期时间等字段因此存在误命中路径；离线使用与坐骑 ID 相同的时间数值复现。

坐骑来源只允许从增益光环入口追加：SetUnitAura／SetUnitBuff 在读取法术数据前拒绝所有包含 HARMFUL 的过滤器，包括组合过滤器；原生默认过滤器继续按增益处理。SetUnitDebuff 不注册来源挂钩。通用 OnTooltipSetSpell 不再注册追加逻辑，避免绕过增益／减益分类；聊天链接与坐骑面板继续通过各自明确入口显示来源。

增益光环只读取既有已支持的法术 ID 字段，或通过光环名称查询法术信息；无法解析时静默跳过。光环挂钩不会在读取失败后复用提示框残留的 GetSpell() 结果。玩家可见文案保持原样。

## 迁移与加载边界

- 完整迁移单元：MoP 光环 ID 读取与 SetUnitAura／SetUnitBuff 挂钩，归入 `Mists/AuraTooltip.lua`；Tooltip 的来源排版、去重、链接与收藏状态等职责保持原位。
- 适配契约：`ReadBuff(unit, index, filter)` 返回法术 ID 或 nil，以及光环是否存在；`Initialize(tooltip, apply)` 仅向共享渲染回调传递增益入口已解析的 ID。
- 受影响的已支持目标仅 Mists。Forever 仍处于独立取证准备阶段，没有正式目标加载本模块。
- 既有 `YiboMounts.toc` 加载适配模块一次；测试入口同步加载。没有改名 TOC、安装目录或 SavedVariables，旧包覆盖时沿用原清单；旧 Tooltip.lua 被同路径更新，没有新增旧路径执行入口。正式覆盖包与客户端生命周期验收仍待发布前完成。
- 构建按 TOC 收集运行文件，Mists 构建 ValidateOnly 通过；1.0.1 安装包、源码归档与覆盖检查的实际结果保存在仓库 `_NonRelease/Mounts-1.0.1-20261025/`，渠道发布状态另行登记。

## 验证与 Core 审查

- Lua 5.1 冒烟测试通过，包括原有来源格式化、Tooltip 状态、链接、坐骑面板及诊断测试。
- 新增 AuraTooltipSmoke：覆盖时间字段碰撞、旧提示残留 ID、未知光环不截断扫描、正常光环 ID、名称解析、非坐骑减益、API 缺失与 player／target 回调。HARMFUL 及三种组合过滤器在两个光环 setter 和两个单位下均在读取前拒绝，即使模拟返回坐骑目录中的法术 ID 也不显示来源；实际初始化验证不注册通用法术／专用减益追加入口，默认／明确 HELPFUL 的坐骑增益保留来源。
- 正式 TOC 的 12 份 Lua 文件语法检查通过；新增回归脚本由 Lua 5.1 实际执行。
- 已运行工作区本地化检查并查看报告；本轮无新增文本、资源键或格式参数。报告中的既有目录文本候选与未知键不在本次光环解析职责内。
